# 憨之轨迹 · 序章：归来

可从返乡玩到赴塔出发的本地 HTML 序章。探索借鉴 PokeMMO 合众地区的俯视／斜视观感，使用代码绘制的原创像素占位场景；战斗沿用已认可的 1V1 规则及 2.5D 镜头。没有复制 PokeMMO 素材。

## 运行

打开本目录的 `index.html`，所有脚本、样式均在本目录，无 npm 依赖、构建步骤或外部网络资源。建议桌面 Chrome / Edge；也可通过任意本地静态 HTTP 服务打开。当前会话预览地址为 `http://127.0.0.1:8083/`，该临时服务不随文件同步，关闭进程后需要重新启动。

有 Node.js 时，在仓库根目录运行以下命令（仅监听本机，只提供本序章目录）：

~~~powershell
node -e "const http=require('node:http'),fs=require('node:fs'),path=require('node:path'),root=path.resolve('prototypes/hanser-prologue');http.createServer((q,s)=>{try{let u=decodeURIComponent(new URL(q.url,'http://localhost').pathname);let p=path.resolve(root,'.'+(u==='/'?'/index.html':u));if(!p.startsWith(root+path.sep)||!fs.existsSync(p)||!fs.statSync(p).isFile()){s.writeHead(404);return s.end('Not found');}s.writeHead(200,{'Content-Type':({'.html':'text/html; charset=utf-8','.js':'text/javascript; charset=utf-8','.css':'text/css; charset=utf-8','.png':'image/png'}[path.extname(p)]||'application/octet-stream'),'Cache-Control':'no-store'});s.end(fs.readFileSync(p));}catch{s.writeHead(400);s.end('Bad request');}}).listen(8083,'127.0.0.1',()=>console.log('Open http://127.0.0.1:8083/'));"
~~~

本轮实际验证使用 HTTP；file:// 双击入口尚未实测。若有 Python，可在本目录运行 `python -m http.server 8083 --bind 127.0.0.1`，再访问上述地址。没有 Python 时直接打开 HTML，或用编辑器的本地预览。保存检查点依赖浏览器允许 localStorage；不同浏览器、端口及 file/HTTP 地址之间不共享存档。实际验证范围见 [VERIFICATION.md](VERIFICATION.md)。

## 完整流程

归乡路行走 → 调查家门 → 疏散广播、满穗逃亡、魔导盘落地 → 拾取并拟态 → 战士首战 → 净化、满穗昏迷 → 屋内对白、银狼礼物与托付 → 满穗寄宿 → 镇内两处居民调查（顺序自由）→ 路口退缩、小册子与选择 → 赴塔路上的法师战 → 净化 → 向北出发、序章结束。

外围与镇内是两个可往返的小区域。屋内为自动剧情布景，不额外增加室内探索区域。公告栏是可选调查点。两位居民均调查后，中央路口出现主线标记；作出赴塔决定后才能接入第二战，胜利后继续向北调查出口，完成序章。

主要故事依据 [《序章·归来》](<../../docs/《憨之轨迹》· 序章·归来.md>)。长篇叙述被改写为逐句对白、场景动作与旅途记录；保留人偶、卡带、通道失效、净化恢复、礼物、寄宿与主角自主选择等主要内容。第二战对白、环境短句、视觉与技能名称为本轮获批的试玩衔接；不覆盖原话本，也不把后来讨论的分阶段揭密试案写成正式设定。

## 操作

| 功能 | 键盘 | 鼠标 |
| --- | --- | --- |
| 行走 | WASD / 方向键，Shift 加快 | 点击可达地面自动寻路 |
| 调查 | 靠近后 E / Enter / Space | 点击人物、物件标记或底部调查按钮 |
| 对白 | Enter / Space / E；首按补全文字，再按下一句 | 点击“继续” |
| 旅途记录、技能搭配 | M，再用 Tab / Enter 操作按钮 | 右上“旅途” |
| 暂停 | Esc；菜单内 Esc 先返回 | 右上“暂停” |
| 战斗菜单 | ↑ ↓ / W S 或 1–4，Enter 确认 | 点击对应指令，确认目标 |
| 闪避 / 精准格挡 | J / K | 点击“闪避” / “格挡” |
| 可选共鸣 | Space | 点击“共鸣” |
| 大招 | R；选招时确认目标，动作中预约 | 右下大招入口 |

金色标记指向当前主线；战斗时间条接近右侧亮区再输入。红光攻击不可格挡，下一击仍可独立应对。共鸣失误保留基础效果。普攻恢复技力；物品消耗正常行动。大招在当前完整行动后插入，不占原定正常行动。

## 首战教学

满穗带领玩家完成七步：普通攻击 → 闪避 → 碎光与共鸣 → 精准格挡 → 药剂 → 红光闪避 → 大招。只需三次普通行动（攻击、技能、药剂）加一次大招，即可获胜并进入后续剧情。每步只开放当前要练习的指令，支持鼠标和键盘，确认目标前可按 Esc 返回。

首战使用临时基础招式，不覆盖旅途中保存的装配。玩家以 90/120 生命开始，方便实际观察药剂恢复；卫兵为 90 生命，三次攻击均简化为慢速单击、每击基础伤害 4。应对标记到达有效时机后会停住等待，按早或按错不消耗练习机会。最后由满穗补充至 60 能量，练习大招收尾。

第二场法师战恢复正常战斗规则和玩家装配，不会停在亮区等待输入；共鸣可选，错过仍保留基础效果，格挡需要把握更短的时机。首战中刷新或重进会从第一步教学恢复，先前剧情保持完成。

## 检查点与恢复

- 每个剧情段完整结束后提交事件；探索时定期保存位置。
- 未读完的对白刷新后从该段开头重播，不会丢失先前完成的事件。
- 战斗刷新、失败重试时从该场初始状态恢复；保留剧情、调查及装配。
- 每场开始恢复 3/6 技力、0 大招能量和 3 份药剂；首战教学以 90/120 生命开始，第二战恢复 120 生命。跨战不继承消耗。这些均为试玩值。
- 窗口失焦、页面隐藏会暂停探索与战斗；可见帧短暂卡顿会限制时钟推进，避免一次跨过所有反应窗口。
- 损坏或不兼容存档会被拒绝；不允许完成标记缺失的存档直接跳章。浏览器禁用存储时提示并允许继续当前旅途。
- “重新开始”会在游戏内确认后替换当前浏览器的序章检查点。

## 当前边界

这是独立 HTML 可玩原型，尚未移植 Unity。像素角色、建筑、2.5D 舞台、拟态与净化均为程序占位表现；没有正式模型、角色立绘、配音、授权音乐或素材下载。可开启少量合成操作音效，默认关闭。正式美术、人工节奏与难度调校留待试玩反馈。10–15 分钟是设计目标，并非已经完成的人类首玩时长测量。

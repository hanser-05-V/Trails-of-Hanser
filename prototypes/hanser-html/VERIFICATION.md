## 新版界面的实际操作

通过本机 HTTP 预览，使用真实鼠标拖动与按钮操作；没有注入游戏状态或直接调用游戏规则函数。

| 操作 | 本次结果 |
| --- | --- |
| 小刀、弓箭、魔法拖入横向序列 | 分别从回合 1 推进至 2、3、4，三个槽位正确显示 |
| 第一个招式拖到第三个招式 | 排序为弓箭、魔法、小刀，回合仍为 4 |
| 移动卡拖到障碍 | 提示无效，回合仍为 4，生命与队列不变 |
| 回血拖到毛怪 | 生命 16 → 19，回合仍为 4，卡进入弃牌堆 |
| 点击释放，三招逐一拖向东方向圈 | 前两招不结束回合，第三招后进入回合 5 |
| 连招后的冷却 | 小刀 1、弓箭 2、魔法 2，释放当回合未提前递减 |
| 闪现拖到两格内空地 | 从 (-2,1) 到 (-2,-1)，跨越中间障碍，仍为回合 5 |
| 移动卡拖到相邻空地 | 移动到 (-1,-2)，进入回合 6 |
| 额外卡拖到序列旁的弃牌按钮 | 在回合末超限阶段成功弃牌，解除锁定并进入下一回合 |
| 序列招式拖到移出按钮 | 免费移出，剩余招式正确补位，回合不变 |
| 敌人详情 | 战场敌人可显示方向、范围、伤害及范围内目标；侧栏 DOM 已移除 |
| 战败返回 | 初始生命 1，等待至第 3 回合出现战败浮层；返回配置浮层并重新开始成功 |

超限场景使用生命 99、抽牌概率 100%、手牌上限 1：第 2 回合末进入选弃阶段，拖弃回血卡后进入第 3 回合，再正常抽取新回合卡牌。

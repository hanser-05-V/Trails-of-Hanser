## 打开试玩

用 Chrome 或 Edge 打开同目录的 **index.html**，点击“进入测试战场”。文件独立包含样式、图标、规则和界面，没有外部资源、安装步骤或联网要求。实际自动化浏览器验证通过本机 HTTP 预览进行；file:// 双击打开未由自动化工具实测。

## 三类卡牌

| 类别 | 本版内容 | 获得方式 |
| --- | --- | --- |
| 基础卡 | 移动、普通攻击 | 每个玩家回合开始各保证一张；已有的不叠加，完全不依赖抽牌 |
| 战斗序列卡 | 小刀、弓箭、魔法 | 开战即可选择；各自只能入队一次，使用后冷却 |
| 额外能力卡 | 闪现、回血 | 从配置卡组概率抽取，只有这类计入手牌上限 |

战场占据主画面，三类卡牌横排贴底，三个战斗序列槽位位于卡牌上方。没有右侧行动记录或敌人列表；敌人意图直接显示在战场，悬停查看详情。生命、回合与增援信息显示在画面上方。入口配置与结果使用浮层。

卡牌写明效果、使用方式和冷却，悬停可查看完整说明。冷却中、已入队或当前阶段不可使用时仍显示卡面，但禁止操作。

## 拖到哪里

| 卡牌／区域 | 拖放目标 | 回合消耗 |
| --- | --- | --- |
| 移动 | 相邻有效空格 | 1 |
| 普通攻击 | 相邻敌人 | 1；无目标不能执行 |
| 小刀、弓箭、魔法 | 卡牌上方的战斗序列 | 每加入一张消耗 1 |
| 序列中的卡 | 其他序列位置，或“移出序列”区 | 免费 |
| 当前连招卡 | 点击“释放整组”后，把序列中的当前卡拖向战场方向圆圈 | 整组仅消耗 1 |
| 闪现 | 两格内有效空地 | 准备阶段免费 |
| 回血 | 白色毛怪 | 准备阶段免费 |
| 任一额外能力卡 | 序列旁的“拖此弃牌”区 | 免费；回合末超限时必须自行选弃 |

拖动时显示卡牌浮影，有效格或区域会高亮。拖到障碍、错误目标、页面空白处等无效位置，不消耗卡牌和回合。

也可先点卡，再点目标。序列保留左右箭头和移出按钮。等待使用独立按钮。快捷键：1 选择移动，2 选择普攻，3 等待，Esc 取消选择或当前拖动。按钮、卡牌、棋盘格均支持 Tab / Enter。连招期间 Esc 只能取消当前拖动，不能终止连招。

### 一个简单开局

1. 把“小刀”拖入卡牌上方的战斗序列。
2. 观察敌人图标和攻击预告，再决定移动、普通攻击或继续备招。
3. 点击“释放整组”，将当前招式拖向棋盘上的方向圆圈。
4. 敌人行动完后，移动和普通攻击卡重新补齐；招式根据冷却重新开放。
5. 抽到闪现或回血后，将其拖到对应目标，在本回合行动前免费使用。

不要求一次准备满三张。移动、普攻、等待和普通受伤都不会清空已经准备的招式。

## 保留的回合规则

- 移动、普攻、等待、准备一招、释放整组分别消耗一个完整回合。
- 连招顺序开始后锁定，逐招选择方向；允许空挥，必须执行到底，不能插入额外能力卡。
- 敌人只在整组全部结束后行动。中途击败最后敌人，仍要执行剩余招式。
- 新释放招式当回合末不减少冷却，从下一完整回合末开始减。免费操作不推进冷却。
- 使用或弃掉的额外卡进入弃牌堆。抽牌堆耗尽时只洗回弃牌堆，手牌不参与。
- 回合结束超过手牌上限时，行动暂停，必须手动选弃。弃牌达标后完成本回合结算，再开启下一回合；下一回合新抽牌可以再次超过上限，先允许正常准备阶段操作。
- 常规敌人攻击锁定方向，玩家移动或闪现不会让它重新瞄准。被击退后范围随新位置平移。敌人攻击可以误伤其他敌人。
- 已预告的移动落点被占用则失败，原地结束，不临时替换成攻击。

## 仍属临时处理的边界

1. 结算顺序为玩家完整行动 → 敌方依登场顺序行动 → 超限选弃 → 冷却 → 胜负检查。死亡时直接结束，不要求已死亡玩家弃牌；同时死亡优先判败。
2. 攻击射线遇障碍截断。弓箭只伤害第一名敌人；魔法贯穿角色。魔法先批量伤害，再由远到近尝试击退，受阻不追加伤害。
3. 增援在预告后的下一玩家回合开始入场，先显示意图，玩家行动后正常参与敌方阶段。出生格占用则延期一回合，保留提示与待登场标记；尚有增援不能提前获胜。
4. 相同种子、配置和操作序列可以复现。抽牌/洗牌与敌人决策使用独立随机流。这只是测试方案，不替正式整关重开随机规则作决定。
5. 战败结果页返回入口，保留表单配置；再次进入时重置整关临时状态。本原型关卡只有一场战斗。
6. 本版没有连招自伤、反击等效果，未制定未来复杂中断的正式规则。

读懂回响

菜单点击角色旁的指令，或用 ↑ ↓ / W S 选择、Enter 确认。1 / 2 / 3 / 4 可选当前列表对应项。目标选择招式后预览目标。点击角色、确认按钮，或按 Enter 施放。点击返回或 Esc 可取消，不扣费。卡点动作附近的光圈收向内环时，点击“共鸣”或按空格。漏按保留基础效果。应对点击闪避 / 格挡，或按 J / K。闪避较宽容，格挡要求更精确；红光无法格挡。每击独立、只接收一次选择。大招选招阶段可预览并确认大招；动作期间点击右下大招入口或按 R 预约，整组动作结束后插入。暂停主菜单或动作期间按 Esc，或点击右上暂停。子菜单 Esc 为返回。系统失焦时暂停，点击继续或 Esc 恢复。

鼠标和键盘均可独立完成全部流程，也可随时混用。长按不会自动应对后续攻击。

# 待讨论事项

项目：憨之轨迹 / Trails of Hanser

记录日期：2026-09-29

此页记录尚未作出决定的事项。它们不属于已确认设定，也不是已经完成的开发功能。

## 1. 当前优先：战斗形式

用户希望参考《空之轨迹》《黎之轨迹》。目前尚未选择：

- 以行动顺序为核心的指令战斗。
- 场景即时战斗与指令战斗相结合。
- 对上述系统作适合本项目的简化或组合。

“自由探索后进入能移动站位的指令战斗”是讨论中的建议，尚未批准。

参考资料：

- [Falcom：原版《空之轨迹 FC》战斗系统](https://www.falcom.co.jp/ed6/battle/r02_bt.html)
- [Falcom：《黎之轨迹》战斗系统](https://www.falcom.co.jp/kuro/system/)

原版《空之轨迹》与重制版的系统不同，后续讨论应明确参考版本。

## 2. 战斗确定后继续讨论

- 单人作战或队伍作战，以及同伴是否加入。

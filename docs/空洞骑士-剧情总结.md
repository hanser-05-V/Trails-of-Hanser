# 《空洞骑士》剧情总结与叙事参考

整理日期：2026-10-20  
用途：为毕业设计《憨之轨迹》后续的剧情讨论保留参考。  
范围：《空洞骑士》本体及已发行内容包涉及的主要故事、人物关系与结局，包含完整剧透；玩法只在理解叙事所必需时提及。

> **当前讨论背景**：用户已确认喜欢《空洞骑士》，并希望为毕业设计积累剧情参考。具体最喜欢的人物、情节、主题，以及希望借鉴哪些叙事安排，尚待进一步讨论。
>
> **阅读约定**：原作展示、人物陈述与本文解读分别标明。角色对白可能包含立场、误判与有限认知，不能自动视作世界观的绝对答案。“借鉴方向”仅是后续讨论素材，尚未成为《憨之轨迹》的正式设定。
>
> 本文不指定唯一正史结局，也不使用《丝之歌》的后续信息反推本体全部悬念。来源以游戏对白、物品说明、过场演出及其社区整理为主；引用 Wiki 时，注意区分页面中属于本体和续作的内容。

## 1. 故事概览：回到一个已经失败的拯救计划

一位沉默的小骑士来到地下王国圣巢。这里曾有繁荣的城市、交通与信仰，如今只剩废墟、少数清醒的居民，以及受感染支配的躯壳。

小骑士逐渐发现，王国没有单纯地被外敌毁灭。灾难与统治者对永恒的追求、被遗忘的古老神祇，以及一项牺牲无数后代的拯救计划有关。小骑士自身也是这一计划留下的产物。

故事最终把选择交给小骑士：继续承担旧有封印，还是面对感染的源头，尝试结束令王国停滞的安排。来源：[小骑士的背景与主要经历](https://hollowknight.wiki/w/The_Knight)、[Hornet 的本体对白](https://hollowknight.wiki/w/Hornet_(Hollow_Knight)#Dialogue)。

**解读**：这是一段调查王国覆灭原因的旅程，也是一段逐渐发现“我为什么被创造”的旅程。世界的历史最终落在主角自己的身体与身世上。

### 1.1 几个容易混淆的名称

| 名称 | 本文中的含义 |
| --- | --- |
| 小骑士／The Knight | 玩家控制的沉默主角，没有正式个人姓名。 |
| 空洞骑士／The Hollow Knight | 白王挑选出来、承担封印辐光使命的另一名容器。 |
| 纯粹容器／Pure Vessel | 神居呈现的、未受感染侵蚀的空洞骑士形态；不宜将这一形态视为其历史经历的完整复原。 |
| 容器／Vessels | 白王与白夫人的后代，经由虚空形成、用于封印辐光的存在。 |
| Hornet | 白王与赫拉的女儿，与小骑士、空洞骑士同父；她不是容器，也不具有他们那种虚空本质。 |
| 辐光／The Radiance | 与梦境、光和蛾族有关的高等存在，也是感染的源头。 |

来源：[容器](https://hollowknight.wiki/w/Vessels)、[空洞骑士](https://hollowknight.wiki/w/The_Hollow_Knight)、[Hornet](https://hollowknight.wiki/w/Hornet_(Hollow_Knight))。

## 2. 王国往事：被遗忘的光与永恒的承诺

### 2.1 蛾族曾经敬奉辐光

辐光是蛾族起源中的光。蛾族曾敬奉她，后来转而追随以国王形态出现的 Wyrm，也就是白王。先知将这段历史理解为族人的背弃，并对祖先的选择怀有愧疚。

辐光几乎被遗忘，但有关她的记忆并未完全消失。残留的信仰与痕迹，使那道古老的光重新进入圣巢居民的梦境。来源：[先知最后的对白](https://hollowknight.wiki/w/Seer#Dialogue)。

辐光的重新显现逐渐成为感染：虫子的思想受到侵入，意志被压制，身体与行为出现异常。感染所承诺的共同归属，以失去独立思考为代价。它也能够操纵部分已经死去的躯壳。来源：[辐光的背景、对白与文本出处](https://hollowknight.wiki/w/The_Radiance)。

**解读**：这里的“被遗忘”有现实后果。信仰更替留下的旧问题，并没有因王国建立了新的叙事而消失。玩家探索遗迹，也是在接近被官方荣耀遮住的历史。

### 2.2 白王建立了圣巢，也许诺它能够长存

白王原本是一条古老的 Wyrm，在王国边缘留下巨大蜕壳，以较小的形态出现。他扩展了部分虫族的心智，建立王国，并要求臣民的效忠。

圣巢的道路、车站与建筑记录着他的统治。关于王国永续的承诺，也让他不只是行政上的国王，而成为臣民敬奉的对象。来源：[白王的来历与统治](https://hollowknight.wiki/w/The_Pale_King)。

**理解边界**：不能因此写成“白王创造了所有生命，所有虫子在他到来前都没有思想”。世界上存在更早的文明、不同的高等存在，以及没有接受他统治的群体。

**解读**：白王真正想保住的东西包含文明、臣民与自己的承诺。这样的目标可以令人理解，却不会自动使他使用的手段正当。

### 2.3 容器计划：用无法被侵入的“空”封住感染

白王试图利用虚空对抗辐光。他与白夫人的后代在深渊中成为容器，计划从中选出能够永久承载辐光的个体。

深渊堆积着大量被舍弃的容器外壳。它们并非无关的背景装饰，而是这项计划实际付出的代价。白王选中空洞骑士后，封闭了深渊入口；死亡容器留下的暗影仍在那里游荡。来源：[深渊的历史与环境](https://hollowknight.wiki/w/The_Abyss_(Hollow_Knight))。

出生地回忆中的白王之言，提出了理想容器的要求：没有可以思考的心智，没有可以被击破的意志，也没有表达痛苦的声音。

**理解边界**：这些要求首先说明白王的计划与期待，不能单凭这段宣言就断言每一个容器事实上完全没有思想、意志或情感。来源：[白王的出生地回忆对白](https://hollowknight.wiki/w/The_Pale_King#Dialogue)。

**解读**：计划的恐怖不仅来自牺牲数量，也来自命名方式。“孩子”被理解为“容器”，能够建立关系的生命被要求成为没有内在世界的工具。

### 2.4 被选中的空洞骑士并不真正空洞

空洞骑士被带离深渊、培养长大，最终承受辐光，并被锁在黑卵之中。然而封印没有永久维持，感染重新出现。

白夫人明确指出，原先对这一容器的判断有误，它受到某种被灌输的观念影响。她最初仍希望小骑士替代它，继续完成封印。白夫人也承认自己对容器计划负有责任，因此自缚于王后花园，限制继续繁衍的欲望。来源：[白夫人的本体对白](https://hollowknight.wiki/w/White_Lady#Dialogue)。

苦痛之路尽头展示了白王与幼年空洞骑士相处、彼此注视的短暂画面。这为一种常见解释提供了依据：被培养的孩子与父亲形成羁绊，正是“空洞”理想的裂缝。来源：[白色宫殿与苦痛之路](https://hollowknight.wiki/w/White_Palace#Sub-area:_Path_Of_Pain)。

**理解边界**：游戏没有明确把那种观念命名为“父爱”，也没有完整交代它如何产生。父子羁绊导致不纯是有证据支持的解读，不能写成已经被对白逐字确认的唯一答案。

**解读**：这一留白使计划带有反讽。白王试图制造能够承担牺牲、服从使命的后代，却又需要这个后代没有任何可以被使命与关系触动的内心。

### 2.5 三位守梦者：相同的封印，不同的理由

守梦者进入长眠，以自己的力量维持黑卵外部的封印。小骑士必须进入他们的梦境，使三道封印逐一解除，才能抵达黑卵中的空洞骑士。三人并非完全一致的集体。来源：[守梦者的作用与集体对白](https://hollowknight.wiki/w/Dreamers)。

| 守梦者 | 参与计划与面对现在的态度 |
| --- | --- |
| 守望者卢瑞恩 | 对国王与泪水之城怀有忠诚，希望通过长眠继续守护城市；面对小骑士时，仍坚持封印应当维持。 |
| 教师莫诺蒙 | 为拯救圣巢参与封印；后来认为永远不变的停滞需要结束，接受封印被打破。 |
| 野兽赫拉 | 深巢的统治者。她参与计划的条件，是与白王拥有一个孩子；这个孩子就是 Hornet。 |

来源：[卢瑞恩的日记与梦之钉对白](https://hollowknight.wiki/w/Lurien_the_Watcher)、[莫诺蒙的经历与对白](https://hollowknight.wiki/w/Monomon_the_Teacher)、[赫拉的本体背景与对白](https://hollowknight.wiki/w/Herrah_the_Beast)。

赫拉与 Hornet 相处的时间很短，随后便进入长眠。她的梦中残语反复指向孩子与那场交易。因此，不能把她简单归纳为出于对白王的忠诚而献身。

**解读**：三位守梦者让同一项历史决策拥有不同的人性来源。忠诚、对世界的责任与对孩子的愿望，都可能把人带到同一位置；当方案失效时，他们也不必给出同一种回应。

### 2.6 圣巢最终成为遗迹

封印失效后，感染再次蔓延，王国无法恢复昔日秩序。白王与宫殿从原址消失；小骑士后来在梦境中的白色宫殿找到坐在王座上的白王遗体。

白王的具体死因没有得到明确交代。遗迹证明他最终没能实现永恒，却没有提供一份解释全部过程的历史记录。来源：[白色宫殿的历史与现状](https://hollowknight.wiki/w/White_Palace)。

## 3. 小骑士的旅程：从陌生来客到历史当事人

### 3.1 这次进入圣巢，其实是返回

小骑士也是被舍弃的容器，曾经逃离深渊，并在圣巢之外游荡。开始时，它看起来像进入陌生世界的旅行者；随着线索出现，这次旅行逐渐被重新理解为返乡。

守梦者提出，它的归来可能回应了封印中的容器，或被囚禁的光。游戏没有把召唤来源确定为白王，也没有完整展示小骑士如何逃出深渊、在外界经历了什么。来源：[小骑士的背景](https://hollowknight.wiki/w/The_Knight)、[守梦者对白](https://hollowknight.wiki/w/Dreamers#Dialogue)。

**解读**：这种身份揭晓不是凭空替换主角。先前遇到的相似外壳、遗骸、暗影与称呼，在真相揭开后获得共同解释。

### 3.2 Hornet：从阻拦者到帮助主角作出选择的人

Hornet 最初阻止小骑士继续深入，随后通过交锋确认它的力量与意志。她要求小骑士面对王国的过去，再决定是否承担未来。

她与小骑士共享父亲，但没有容器那种关键的空无本质。她明确表示，黑卵适合容器存在，自己进入则会被其中的束缚消耗。因此，她不能被写成另一名虚空容器。来源：[Hornet 在深渊与黑卵外的对白](https://hollowknight.wiki/w/Hornet_(Hollow_Knight)#Dialogue)。

**解读**：Hornet 的角色价值，在于她既有阻止主角的理由，也有改变判断的能力。她不把自己的答案强塞给小骑士，而是让它具备理解选择代价的条件。

### 3.3 梦之钉让隐藏的历史变得可以接近

守梦者曾试图把小骑士困在梦境中。先知给予梦之钉，使它能够接触梦、残留的思想与记忆。

先知的引导与蛾族的旧事相连。她既是提供帮助的人，也是历史责任的承受者。在最后的坦白中，她承认族人的背弃，并在说出辐光的名字后消散。来源：[先知的经历与对白](https://hollowknight.wiki/w/Seer)。

**解读**：读取思想与进入记忆在这里具有明确的故事用途。它让敌人的外表、现实中的残骸与角色内心不再必然一致，也使“探索世界”逐渐变成“探索世界如何记住过去”。

### 3.4 奎若与莫诺蒙：同行者也有自己的归途

奎若以好奇、友善的旅行者形象出现，多次与小骑士相遇。他对圣巢既感到新鲜，又隐约熟悉，却不完全记得自己的过去。

抵达教师档案馆后，他认出与莫诺蒙的联系，并归还一直戴在头上的面具，解除她身上的额外保护。他解释，这是莫诺蒙主动要求的改变。随后，他前往蓝湖，完成自己想看看泪水之城雨水来源的愿望。最后一次交谈后，他离开了画面，湖边只留下骨钉。来源：[奎若的经历与完整对白](https://hollowknight.wiki/w/Quirrel)。

**理解边界**：这一告别强烈暗示旅程与生命阶段的终结，但游戏没有演出他的死亡方式。不要把“投湖自杀”“立即衰老而死”等具体说法当作已经展示的事实。

**解读**：奎若的线索最终回到早先一个很小的愿望。他帮助世界完成改变后，属于他的结尾是一处安静的风景。宏大事件因这种私人愿望而获得尺度。

### 3.5 破碎容器：主角可能拥有的另一种结局

小骑士在古老盆地遇到另一具容器遗骸。感染寄生物进入破损外壳，使它重新活动并发动攻击。被击败后，它向小骑士伸出手，随后倒下；其梦境形态“失落近亲”还可以留下另一次无声的告别。来源：[破碎容器的背景与演出](https://hollowknight.wiki/w/Broken_Vessel)。

**解读**：相似的外形使玩家在充分理解血缘之前，就先感受到某种亲缘。它也说明小骑士的存续并非所有同类都能拥有的命运。

### 3.6 出生地回忆：被遗弃的过去成为力量来源

小骑士取得白夫人与白王各自留下的王之魂碎片后，能够回到深渊更深处的出生地。

在回忆中，它沿着深渊向上攀爬，看见白王带走被选中的空洞骑士；自己则坠回黑暗。回忆结束后，王之魂转变为虚空之心。物品说明将其作用表述为：使虚空统一于持有者的意志之下。来源：[虚空之心的说明与取得过程](https://hollowknight.wiki/w/Void_Heart)。

**解读**：这个转折没有让主角抹去自己的起源。它通过面对被遗弃的经历，改变了自己与虚空的关系。原先只代表失败与废弃的地方，成为另一条道路的起点。

**理解边界**：虚空之心的“意志”措辞，与白王追求的无意志理想形成张力，但仍不足以单独回答小骑士拥有怎样的人格。更稳妥的写法是保留这种张力，而非替原作给出完整心理诊断。

### 3.7 黑卵中的对手，也是承担过使命的亲族

面对空洞骑士时，小骑士见到的不是全盛时期的英雄，而是被感染侵蚀、逐渐无法维持动作的身体。战斗中，空洞骑士会反复刺向自己的胸口，身体随后更加衰弱。来源：[空洞骑士战斗演出](https://hollowknight.wiki/w/The_Hollow_Knight)。

**解读**：自刺动作使“击败最终敌人”的情境发生变化，玩家可能将它理解为挣扎、抵抗或求助。但原作没有直接说明每个动作背后的意图，因此不宜确定地写成“它完全恢复清醒，主动教玩家如何杀死自己”。

## 4. 五种通常归类的结局

以下按照故事分歧整理，不提供具体战斗攻略。前三种发生在黑卵相关路线；后两种来自 Godmaster。Godmaster 是已经发行的官方内容包。来源：[Team Cherry 的 Godmaster 发布公告](https://www.teamcherry.com.au/blog/hollow-knight-godmaster-is-out-now-for-all-players)。

| 结局 | 关键条件 | 直接结果 |
| --- | --- | --- |
| The Hollow Knight／空洞骑士 | 未取得虚空之心，击败空洞骑士 | 小骑士成为新的封印容器。 |
| Sealed Siblings／封印的同胞 | 已取得虚空之心，但在 Hornet 介入后仍击败空洞骑士 | 小骑士承担封印，Hornet 也被封入黑卵。 |
| Dream No More／不再有梦 | 取得虚空之心，经 Hornet 创造的机会进入梦境，击败辐光 | 感染源被消灭。 |
| Embrace the Void／拥抱虚空 | 在圣巢万神殿击败无上辐光，未向寻神者赠花 | 辐光被消灭，虚空从寻神者体内向现实显现。 |
| Delicate Flower／娇嫩的花变体 | 完成同一寻神路线，事先向寻神者赠花 | 花朵使向外涌出的虚空与寻神者一同消失。 |

后两种共用 Embrace the Void 成就。“娇嫩的花”是结局变体的常见分类名；本体没有名为 Hollow No More 的结局。名称与条件核对：[结局总表](https://hollowknight.wiki/w/Endings_(Hollow_Knight))。下文对演出细节的说明另按角色与物品页面列出。

### 4.1 替代：成为新的空洞骑士

第一种结局延续了白王方案的基本结构。原先的容器死亡，小骑士吸收感染并被封在黑卵之内。来源：[小骑士的黑卵路线](https://hollowknight.wiki/w/The_Knight#In-game_Events)。

**解读**：标题在这里落到玩家身上。旅途的终点是成为前人留下的职位，也承受那个职位的代价。画面没有保证新封印能够永久成功，更没有证明辐光已经被消灭。

### 4.2 共同被封：Hornet 也进入牺牲结构

第二种结局中，Hornet 介入后被击昏，最终与小骑士一起留在黑卵内。黑卵门上出现她的形象，与先前三位守梦者的印记相似。来源：[Hornet 在各结局中的处境](https://hollowknight.wiki/w/Hornet_(Hollow_Knight)#Endings)、[小骑士的结局经历](https://hollowknight.wiki/w/The_Knight#In-game_Events)。

**解读**：援助者也被纳入了旧方案的代价。这个结局尤其强调，拥有改变局势的机会，并不等于一定完成改变。

### 4.3 不再有梦：直接结束辐光

在梦境中，虚空逐渐包围辐光。空洞骑士的暗影出现，帮助打开她的防御；小骑士的暗影完成最后攻击，辐光被虚空吞没，感染由此终止。来源：[辐光的终局](https://hollowknight.wiki/w/The_Radiance#In-game_Events)。

随后，Hornet 在黑卵消失后的空间醒来，看见小骑士破裂的外壳；深渊中的同胞暗影逐渐沉下。来源：[Hornet 的结局经历](https://hollowknight.wiki/w/Hornet_(Hollow_Knight)#Endings)、[Dream No More 过场说明](https://hollowknight.wiki/w/Endings_(Hollow_Knight)#Ending_3:_Dream_No_More)。

**解读**：主角没有把使命完整转交给下一个容器，而是改变了问题的处理方式。曾经分别被选中与舍弃的同胞，在终局中共同作用于施加在他们身上的命运。

### 4.4 拥抱虚空：感染结束，新的力量留下悬念

寻神者来自失去旧神的群体，试图在圣巢寻找值得敬奉的新神。神居是其集体心灵中的梦境空间；仪式通过与强大存在共鸣，逐渐接近她认定的至高神。

当小骑士最终战胜无上辐光时，虚空凝聚出巨大形态，并取代原先被寻求的神。此后，虚空侵入神居，也从现实中的寻神者身体涌出。来源：[寻神者的背景与结局](https://hollowknight.wiki/w/Godseeker)。

**解读**：这一结局提供了消灭感染的另一条道路，却没有把新力量的未来行为全部说明。不能直接续写成“虚空确定毁灭圣巢”，也不能保证它会成为保护所有居民的新王。

在包含黑卵后续镜头的演出中，感染组织枯萎，一个拖着锁链的身影出现，Hornet 随即戒备。该身影通常被辨认为摆脱封印使命的空洞骑士；画面在双方后续行动发生前结束。来源：[空洞骑士在 Godmaster 中的结局](https://hollowknight.wiki/w/The_Hollow_Knight#In-game_Events)。

**演出条件**：当前版本的上述黑卵镜头与黑卵入口是否已经打开有关，不能概括为所有游玩状态都会播放。来源：[Embrace the Void 的镜头显示条件](https://hollowknight.wiki/w/Endings_(Hollow_Knight)#Ending_4:_Embrace_the_Void)。

### 4.5 娇嫩的花：一个私人礼物改变最后的画面

如果寻神者事先收到娇嫩的花，虚空涌出时会与花朵接触。白光闪过后，寻神者与虚空消失，地上留下花朵。

花朵最初与灰色哀悼者送给亡故爱人的礼物相连。本体中的白夫人也指出，它来自圣巢之外，脆弱花瓣中藏着罕见力量。来源：[娇嫩的花的任务、对白与结局效果](https://hollowknight.wiki/w/Delicate_Flower)。

**理解边界**：结局没有完整说明消失者的去向，也不能仅凭这次接触断言全世界的虚空都被清除。

**解读**：这一分歧让一件与哀悼、赠予有关的小事进入宏大的终局。它改变的不是主角是否有力量击败神，而是胜利之后那股力量如何进入现实。

## 5. 可选支线：重复的仪式与离开的可能

### 5.1 格林剧团

格林剧团在被召唤后进入圣巢，从衰败之地收集梦魇火焰，延续服务于梦魇之心的仪式。小骑士可以帮助格林之子成长，并完成击败梦魇之王的仪式，使循环继续；也可以帮助布鲁姆驱逐剧团。来源：[格林及仪式背景](https://hollowknight.wiki/w/Troupe_Master_Grimm)。

**解读**：这条支线提供了与主线相呼应的结构：某个古老安排通过重复维持自身，而参与者是否愿意继续，并不天然一致。它是独立的可选故事，不应被写成所有结局都必然经历的步骤。

### 5.2 蘑菇先生的额外尾声

完成蘑菇先生相关相遇后，主要结局之外可以出现他飞离的额外画面。它不替代上述主线分歧，更适合视为世界仍在延续的彩蛋。来源：[额外尾声 Passing of the Age](https://hollowknight.wiki/w/Endings_(Hollow_Knight)#Extra_Ending:_Passing_of_the_Age)。

## 6. 对剧情与叙事设计的参考

以下属于本文解读，不是对开发者意图的唯一判断。这些角度用于后续讨论，不代表用户已经决定将它们用于《憨之轨迹》。

### 6.1 让世界之谜与主角之谜最终相交

前期问题是“王国发生了什么”，后期问题变成“我的诞生与这场灾难有什么关系”。两条调查线在深渊汇合，使世界观说明同时成为人物转折。

可参考的是问题的连接方式：主角接近历史时，自己的目标与自我理解也应发生变化。仅仅增加更多背景设定，未必能产生同样效果。

### 6.2 用空间保存历史的后果

交通遗迹显示繁荣，深渊的外壳显示代价，王座上的遗体显示失败。环境不只负责营造氛围，也承担具体证据的功能。

这种方式要求视觉线索能够互相印证。玩家即使没有读完所有文本，也应逐渐建立某些可靠判断，而不只是得到模糊的悲伤感。

### 6.3 同一历史事件，可以由不同利益与感情参与

三位守梦者承担相同功能，却分别连接忠诚、改变与亲情。这样的人物差异，使世界不必围绕统一答案运转。

对创作而言，可以先确定共同事件，再追问每个人为什么来到这里、付出了什么、现在是否还相信当初的决定。人物的差异会自然形成冲突。

### 6.4 留白需要有清楚的边界

苦痛之路没有解释全部感情，却给出了明确的相处画面；奎若没有留下死亡报告，却完成了早已表达的愿望。玩家拥有足够材料感受意义，也仍有解释空间。

有用的留白往往是：事实能够被观察，情感和因果的一部分保持开放。如果连发生了什么都无法判断，讨论容易变成没有共同证据的猜测。

### 6.5 沉默角色也可以拥有关系变化

小骑士不靠长篇对白表达自己，但他人对它的判断会改变。Hornet 从阻拦转为信任，奎若从相遇到告别，白夫人从寻找替代者到承认未来属于它。

因此，沉默主角的叙事并不需要让所有人物停止交流。其他角色的行动、称呼与期待，也能表现主角在世界中的位置如何变化。

### 6.6 结局差异可以改变“解决问题”的含义

替换容器、消灭辐光、经寻神仪式释放新力量，都回应同一危机，却对责任、牺牲与未知后果给出不同排列。

对毕业设计而言，值得先讨论的是：结局究竟改变了什么，是牺牲者身份、问题根源，还是未来的权力关系。这样能够避免仅用不同动画或存活名单区分结局。

### 6.7 小人物的愿望让废墟仍值得关心

奎若想看看雨水的来源，Hornet 需要独自哀悼母亲，灰色哀悼者希望送出一朵花。这些愿望并不负责解释全部世界观，却让玩家明白王国中的生命具体珍惜什么。

可参考之处是把关系与愿望放进日常相遇。等到告别发生时，情感已经有所依附，不需要临时依靠大量说明证明人物重要。

## 7. 后续讨论时应保留的理解边界

- 小骑士与空洞骑士是不同个体，不能用同一个名字混写两者经历。
- Hornet 与容器同父，但不是虚空容器。
- 深渊之外还存在其他容器遗骸，不能说只有小骑士和空洞骑士曾经逃离或存续。
- 白王的“无心、无意志”是容器计划的理想要求，不能直接当作所有容器的已验证心理状态。
- 空洞骑士受到某种观念影响是文本事实；具体等同于父爱或父子依恋，是有线索支持的解释。
- 小骑士的逃离路线、外界经历、召唤来源，以及白王的死因仍有未交代之处。
- 奎若的蓝湖告别没有展示具体死亡过程。
- 纯粹容器是神居呈现的形态；神居中的强者形态不能一律理解为现实历史中的完整原貌。
- “不再有梦”可以被称为直接终结感染的结局，不宜未经说明就称为唯一官方真结局。
- Godmaster 的虚空形态与花朵消失事件保留悬念；《丝之歌》的后续信息应放到续作篇或单独比较中讨论。

这些边界用于把已知事件与解释空间分开，方便之后讨论《憨之轨迹》真正想借鉴的部分。

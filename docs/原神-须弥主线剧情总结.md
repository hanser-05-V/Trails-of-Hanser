# 《原神》须弥剧情总结与叙事参考

整理日期：2026-10-20  
用途：作为毕业设计《憨之轨迹》的剧情讨论资料，梳理人物动机、事件因果与叙事结构。  
范围：须弥魔神任务第三章第一至第五幕，并补充间章第三幕《倾落伽蓝》。前者为 3.0—3.2 版本主线，后者为 3.3 版本补充。**包含完整剧透。**

## 一、这段故事主要讲了什么

须弥以知识和智慧为荣，但掌握知识分配权的教令院，将神明、梦境和普通人的意识都变成可以使用的资源。

旅行者最初想见到草神，逐渐发现：民众依赖的虚空系统在掩盖梦境实验，现任草神纳西妲被自己的国家囚禁，贤者则试图制造一位符合他们期待的新神。故事先让旅行者体验被知识系统困住，再让其与伙伴利用信息、信任和合作解救神明。

主线最后的问题比“夺回权力”更深：如果拯救世界必须删除一个人的全部存在记录，谁还能记住她？后续《倾落伽蓝》继续追问：如果别人忘记了你，你是否也就不必为过去负责？

| 阶段 | 主要事件 | 核心问题 |
|---|---|---|
| 第三章第一幕 | 进入须弥、认识迪娜泽黛、调查神明罐装知识 | 谁决定什么知识可以被人获得 |
| 第二幕 | 花神诞祭轮回 | 人的梦与意识能否被当成资源 |
| 第三、四幕 | 造神计划、沙漠调查、赤王历史 | 权威叙述和群体成见是否可靠 |
| 第五幕 | 解救纳西妲、对抗正机之神、告别树王 | 智慧、牺牲与记忆的关系 |
| 间章第三幕 | 散兵尝试删除自身，恢复记忆 | 忘记过去是否等于改变过去 |

## 二、理解剧情需要的基本前提

### 1. 虚空便利，也使知识分配高度集中

虚空是由草神力量支持、通过终端向人们提供信息的系统。须弥人习惯依赖它求知，能够获得什么信息又受权限等条件影响。

问题并不在于所有知识工具必然有害，而在于教令院掌握系统与解释权后，普通人越来越难以发现自己没有被告知的事情。没有获得某项知识，很容易被理解成自己不需要知道。[任务对白：智慧之神的踪影](https://genshin-impact.fandom.com/wiki/The_Trail_of_the_God_of_Wisdom)

### 2. 纳西妲生活在前任神明的巨大阴影里

大慈树王被视为伟大的智慧之神，在五百年前的灾变中消失。贤者找到幼小的纳西妲，却因其无法表现出期待中的智慧和力量而失望，将其长期隔绝在净善宫。

纳西妲仍尝试通过梦境等方式帮助人们，但在现实政治中没有与神明身份相称的自由。她也受到这种否定影响，怀疑自己是否有资格成为合格的神。[主线概览：穿越烟帷与暗林](https://genshin-impact.fandom.com/wiki/Through_Mists_of_Smoke_and_Forests_Dark)

### 3. 世界树、死域与魔鳞病并不是互不相关的支线设定

旅行者在雨林中接触提纳里、柯莱与死域，看到知识污染已经表现为环境与身体的损伤。

世界树关联着提瓦特的记忆与信息。禁忌知识侵入其中，会产生现实后果；魔鳞病和死域因此与主线的核心危机相连。它们不是只用来增加危险气氛的独立疾病与怪异区域。[终局相关设定：大慈树王](https://genshin-impact.fandom.com/wiki/Greater_Lord_Rukkhadevata)

**理解边界：**禁忌知识不能简单理解成被官方禁止阅读的普通知识。它在这里具有超出世界正常秩序的污染性质，与贤者对一般知识的审查并非同一个概念。

## 三、主要人物及其行动动机

| 人物 | 主要动机 | 在故事中的作用 |
|---|---|---|
| 纳西妲 | 帮助人民，理解世界，也证明自身价值 | 从被否定的幼小神明成长为承担责任的行动者 |
| 旅行者 | 寻找血亲与世界真相，保护已经建立联系的人 | 参与行动，并最终成为被删除历史的见证者 |
| 迪娜泽黛 | 在病痛限制中认真生活，回报曾帮助自己的草神 | 将“拯救须弥”落实为一个人的生命与愿望 |
| 妮露 | 完成花神诞祭，维护艺术和共同庆祝的空间 | 以舞蹈和梦境中的创造力参与关键转折 |
| 艾尔海森 | 弄清异常与真相，制止失控的权力计划 | 提供判断、布局与信息处理能力 |
| 赛诺 | 追查教令院问题，维护职责所指向的正义 | 区分制度职位与制度本应服务的价值 |
| 迪希雅、坎蒂丝 | 保护具体的人，尊重其选择 | 为跨群体合作提供信任与现实基础 |
| 阿扎尔等贤者 | 获得理想中的智慧神明与知识支配能力 | 把人和神当成实现目标的工具 |
| 散兵 | 摆脱被抛弃感，证明自己不再需要人的情感 | 在造神失败后继续面对身份与责任 |
| 博士 | 推进实验与研究，取得有价值的成果和情报 | 把社会、个体与神明作为实验对象 |

## 四、须弥主线：从一场节庆走向整个国家的秘密

### 1. 迪娜泽黛让“草神”成为一个具体的人

迪娜泽黛患有魔鳞病，成长过程受到身体状况限制。纳西妲曾在她孤独时与其交流，鼓励她通过知识认识世界。因此，她对小吉祥草王的信仰不是单纯接受公共宣传，而来自被帮助过的个人经验。

她希望办好花神诞祭，让这位被冷落的神明得到庆祝，也让自己有限的生活留下值得珍惜的经历。迪希雅最初作为护卫保护她，随后也尊重她想要走出安排、亲自生活的愿望。[任务对白：智慧之神的踪影](https://genshin-impact.fandom.com/wiki/The_Trail_of_the_God_of_Wisdom)

**理解边界：**花神诞祭在这段剧情中是庆祝小吉祥草王诞生的节日，不能因为名称中有“花神”就写成花神本人的生日庆典。

另一条线索来自奥摩斯港的神明罐装知识交易。使用这种知识可能引发异常，旅行者也再次听见与世界树有关的神秘话语。这说明知识在须弥不仅是思想内容，也已成为可以交易、灌输甚至伤害人的力量。[神明罐装知识相关任务剧情](https://genshin-impact.fandom.com/wiki/Ever_So_Close)

### 2. 花神诞祭轮回：熟悉的日常变成看不见的监牢

花神诞祭受到大贤者干预，妮露的演出被制止，迪娜泽黛的愿望未能实现。随后，旅行者发现相似的一天不断重演。

食物、对话和事件似乎重复，人们却难以保留清晰认识。纳西妲帮助旅行者找回线索，引导其通过观察理解异常。故事先让旅行者感受到不对劲，再逐步揭开机制，而不是开场就解释全部答案。[任务剧情：千朵玫瑰带来的黎明](https://genshin-impact.fandom.com/wiki/The_Morn_a_Thousand_Roses_Brings)

重复并非没有代价。意识持续受到消耗，身体虚弱的人尤其危险。迪娜泽黛的状况让抽象的“循环问题”变成必须尽快解决的生命问题。

### 3. 真相不是时间倒流，而是意识被困在集体梦中

旅行者通过细节发现，眼前并非现实中的一天反复重启。人们的意识被集中在同一个梦境中，系统持续利用他们在睡眠中产生的活动，收割梦境所蕴含的力量与智慧。

在梦中摘下终端无法真正断开现实中的系统。须弥人长期相信成年人不会做梦，也与虚空对梦的处理有关。[任务对白：轮回意志的花神诞祭](https://genshin-impact.fandom.com/wiki/The_Samsara_of_the_Sabzeruz_Festival)；[任务对白：空幻回响的花神诞祭](https://genshin-impact.fandom.com/wiki/The_Empty_Illusions_of_the_Sabzeruz_Festival)

**解读：**这一段把“信息控制”转成身体经验。受害者不只是听到了错误说法，而是连自己正在经历什么都无法正确识别。观众与旅行者一起推理，因此能够体验权威解释与个人观察发生冲突的过程。

### 4. 妮露的舞蹈打破循环，迪娜泽黛获救

妮露是这一集体梦境的宿主。旅行者通过梦中花朵等线索，让她意识到自己正在做梦；她随后完成原本被阻止的演出，梦境终于得以终止。[任务剧情：终将结束的花神诞祭](https://genshin-impact.fandom.com/wiki/The_End_of_the_Sabzeruz_Festival)；[官方剧情演示：花神之舞](https://www.youtube.com/watch?v=w3KFEs9Rru0)

旅行者一度以为迪娜泽黛已经死亡，但纳西妲寻找并维系了她逐渐消散的意识，使她最终能够在现实中醒来。这不是一个已经正常死亡的人被随意复活；她也没有在此时立刻治愈魔鳞病，疾病的根源要到主线后段才被处理。[任务对白：黎明](https://www.hoyodex.com/wiki/genshin-impact/dawn-quest)

**解读：**艺术在这里不只是装饰。被贤者视为无用、妨碍秩序的舞蹈，成为识别梦境、凝聚共同经历并结束实验的行动。剧情通过事件本身反驳了只有教令院认可的知识才有价值的观念。

### 5. 从梦境实验到造神计划

旅行者与纳西妲继续调查贤者。纳西妲借凯瑟琳的身体参与行动，但博士能够利用虚空影响民众，暴露出系统已经被掌权者用于操控现场局面。[任务剧情：如凯旋的英雄一般](https://genshin-impact.fandom.com/wiki/Like_a_Triumphant_Hero)

海芭夏所接触的“神明”并非她以为的对象，而是正在成为新神的散兵。旅行者由此看见散兵对自身经历的解释：被创造者舍弃、被朋友背叛、又遭遇承诺无法兑现。

这些画面反映的是散兵理解世界的方式，不能全部当作没有偏差的历史结论。随后纳西妲为保护旅行者暴露自身处境，连接受到限制，解救她成为必须完成的行动。[任务对白：来自某位神明的凝视](https://genshin-impact.fandom.com/wiki/The_Gaze_From_a_Certain_God)

造神计划把前面的线索串联起来：梦境实验、神明罐装知识、雷神之心与散兵的特殊身体，共同服务于贤者和博士制造新神的目标。

### 6. 沙漠调查：合作首先要跨过成见

旅行者前往沙漠，与艾尔海森、赛诺、迪希雅等人相遇。众人并非天然互信：赛诺怀疑教令院内部的问题，艾尔海森的行动难以被完全看透，沙漠居民也长期受到区别对待。

坎蒂丝守护阿如村，使不同立场的人有机会在保护村民这一共同目标下交流。失踪学者的线索，则把雨林与沙漠的事件重新连接起来。[任务剧情：剑拔弩张四人众](https://genshin-impact.fandom.com/wiki/The_Four_at_Loggerheads)

被流放、被称为“疯学者”的人并非没有价值的废弃者。他们与异常知识的联系，反而成为造神计划希望继续提取的资源。调查因此揭示了一种更残酷的逻辑：人一旦不能以正常身份进入制度，仍可能被制度当作材料使用。[任务剧情：魔鳞病医院的哭声](https://genshin-impact.fandom.com/wiki/Cry_From_the_Eleazar_Hospital)

### 7. 赤王历史：过去的误解塑造了现在的敌意

遗迹中的记录揭示，赤王曾将禁忌知识带入世界，污染随之扩散。大慈树王前来协助，赤王最终牺牲自身，树王也因耗尽力量而变得幼小。

这推翻了“树王背叛或谋害赤王”的叙述，促使拉赫曼等人重新判断当前合作。共同的历史并不是天然分裂的，但失真的记忆可以长期维持群体敌意。[任务对白：赤土之王与三朝圣者相关终章](https://genshin-impact.fandom.com/wiki/Secret_of_the_Scorching_Desert)

**理解边界：**这里是较早发生的禁忌知识危机，不能与五百年前的灾变混为一谈。树王当时因耗力而变小，也不等于纳西妲已经在那时诞生。角色一度据此提出的猜测，并非故事最后确认的完整真相。

### 8. 解救纳西妲：让控制系统相信错误的信息

团队没有直接冲进净善宫，而是针对贤者对虚空与预测的依赖制定计划。

艾尔海森通过伪装和知识罐装内容制造信息差；妮露的公开演出与伊萨克的伪装帮助引导守卫；迪希雅、拉赫曼等人控制行动中的关键环节；赛诺负责追究阿扎尔；旅行者则接近纳西妲并与其建立联系。[任务对白：识藏日](https://genshin-impact.fandom.com/wiki/Jnagarbha_Day)

行动成功的关键不只是计谋精巧。贤者把人简化为系统可以推算的行为，团队则依靠彼此了解、主动配合与承担风险，做出超出这种简化模型的行动。

纳西妲也需要跨过自己的障碍。长期的否定让她认为自己不够格，而伙伴们的行动使她看到：有人已经因为她的帮助、选择和人格而认可她。她不是先变成另一个大慈树王，才终于值得被救。

## 五、主线终局：击败新神之后，还必须告别旧神

### 1. 正机之神：知识的力量回到众人之间

散兵已经借助雷神之心与机械躯体获得强大力量，成为正机之神。纳西妲没有只靠正面力量压倒对手，而是通过梦中反复演算积累经验，再向须弥人民寻求智慧，将众人的判断汇集给旅行者，最终击败他。[资料条目：斯卡拉姆齐](https://wiki.hoyolab.com/pc/genshin/entry/4583?lang=zh-cn)；[人物剧情整理：纳西妲](https://genshin-impact.fandom.com/wiki/Nahida/Storyline)

**理解边界：**这里明确出现的“168 次”指对抗正机之神时的梦中演算，不能直接写成花神诞祭轮回的已确认次数。

**解读：**同样是连接众人的意识，贤者选择隐瞒与榨取，纳西妲选择说明危机并请求帮助。故事并没有否定集体知识的力量，而是在区分谁有权使用它、使用者是否尊重参与者。

### 2. 大慈树王为何必须被遗忘

纳西妲与旅行者来到世界树相关的意识空间，见到大慈树王留下的意识。

五百年前的危机中，树王本身也受到禁忌知识污染。她与世界树紧密相连，无法靠自己完成对自身的彻底清除，于是留下纯净枝条，使纳西妲诞生。要真正消除残留污染，纳西妲必须删除世界树中关于大慈树王的存在信息。[人物与历史条目：大慈树王](https://genshin-impact.fandom.com/wiki/Greater_Lord_Rukkhadevata)

这不是简单的“树王变小失忆后改名”。纳西妲与树王同源，却拥有自己的经历与成长；她必须以新的主体承担前任无法完成的事。

### 3. 删除完成后，只有旅行者记得告别

纳西妲痛苦地接受请求。她与树王拥抱，随后执行删除。完成后，纳西妲自己也不再记得树王，只留下无法解释的悲伤；旅行者则保留了相关记忆。[官方剧情演示：折枝落梦](https://www.youtube.com/watch?v=tiC-P2tfw0I)

世界中的相关记忆与记录发生改变，人们以新的解释理解草神历史，树王的功绩也被重新归入不再包含她的叙述。

**理解边界：**这一段直接展示的是存在信息、记忆与记录的改写，不宜简单表述成“过去所有相关事件都没有发生”。后续《倾落伽蓝》会更明确地区分删除记忆和改变已发生事实。

### 4. 博士的交易与须弥的善后

博士随后与纳西妲谈判。纳西妲以毁坏神之心可能惊动天理作为威慑，但那是博弈中的判断与试探，不是已经实际发生、得到验证的结果。

两颗神之心对应不同交换：雷神之心换取博士销毁其他切片；草神之心换取重要情报。进行谈判的博士个体仍然存在，不能写成博士已被全部消灭。[任务对白：意识之舟所至之处](https://genshin-impact.fandom.com/wiki/Where_the_Boat_of_Consciousness_Lies)

纳西妲关闭虚空，失势贤者受到处置，须弥开始调整治理。禁忌知识污染的根源被清除后，迪娜泽黛与柯莱的魔鳞病得到治愈。故事给出新的生活可能，却不需要由此推断所有历史矛盾和残留死域都在同一瞬间消失。[任务对白：庆功宴](https://genshin-impact.fandom.com/wiki/A_Toast_to_Victory)

旅行者还得知自己被愚人众列为第四降临者，而血亲在世界树中留有记录，未被归入同一分类。到本篇主线为止，这仍是待解之谜，不能用更晚版本的信息倒填成角色当时已经知道的答案。

## 六、后续补充：《倾落伽蓝》如何重写散兵的自我认识

### 1. 他以为的背叛，包含被制造的谎言

主线战败后，散兵在纳西妲安排下进入世界树调查。新的记忆揭示，踏鞴砂旧事中的关键人物埃舍尔实际是博士。

博士制造危机、杀害丹羽，并利用其心脏及相关谎言操控散兵，让散兵相信自己遭到抛弃。散兵曾用来解释一生的重要事件，因此出现根本变化。[踏鞴砂真相相关任务对白](https://genshin-impact.fandom.com/wiki/The_Night-Bird_Falls_at_the_Curtain%27s_Call)

**理解边界：**揭露受骗不等于散兵之后的全部行为都失去责任。受害经历解释了他如何形成某些判断，却没有自动取消他对其他人的伤害。

### 2. 删除自己，没有让受害者复活

散兵试图从世界树中删除自身，希望如果自己不曾存在，过去被卷入的人就能获得另一种结局。

操作后，人们忘记了他，相关记录被改写，他本人也失去记忆。但旅行者回到稻妻核对发现，踏鞴砂的灾难和雷电五传受到的伤害仍然发生，只是人们用别的人物与原因解释这些结果。[任务对白：乱世轮舞](https://genshin-impact.fandom.com/wiki/A_Dance_of_Destruction)

所以，这不是成功穿越回过去，也不是丹羽等人获救。改变的是世界如何记述已经发生的事情，而非把发生过的悲剧直接取消。

### 3. 恢复记忆，是主动接受自己曾经做过什么

纳西妲预先用寓言形式保存了相关信息，使关键内容没有以直接指向散兵的形式被一并删除。旅行者保留的记忆帮助她重新理解这份备份。

失忆后的流浪者在得知情况后，主动选择取回旧记忆。面对过去与梦中的威胁，他不再把成为神、抹去自己或摆脱人的感情当成唯一答案，并获得风元素神之眼。[恢复记忆相关任务对白](https://genshin-impact.fandom.com/wiki/The_Kabukimono%27s_Finale)

**解读：**这不是一个无辜的新人物替旧人物接受惩罚，而是同一个人决定重新承认自己的经历。他不再只想拥有一个能证明自身价值的身份，而开始处理自己与别人之间真实存在的关系。

### 4. 破碎的花瓶：遗忘不能代替承担

派蒙先前打碎的花瓶仍然破碎，尽管她已不记得原来的原因。这个小物件把庞大的世界树问题收束到可观察的事实：原因可以在记忆中被重新解释，结果却没有因此自动恢复。

流浪者也要求旅行者将相关真相告诉受害者后人，承认他们追究自己的权利。恢复的是他的个人记忆，并不是全世界同时重新记起一切。[任务对白：如朝露一般](https://genshin-impact.fandom.com/wiki/As_Though_Morning_Dew)

章末出现的神秘声音，在本篇范围内尚未正式揭示身份。这里不使用后续版本的信息提前解释。

## 七、这段剧情值得分析的叙事方法

以下为叙事解读。

### 1. 用相同意象讨论不同层次的问题

梦最初是被压制的私人生活，后来成为剥削工具，再成为反抗与合作的方式；记忆最初帮助旅行者破解轮回，后来成为告别的代价，最后成为散兵必须主动承担的责任。

这些元素不是反复出现的装饰，而是在不同情节中改变意义，使主线与间章形成连续讨论。

### 2. 把宏大危机绑定在一个人的愿望上

迪娜泽黛想看完一场演出、认真度过自己的生命。这种愿望并不宏大，却让“虚空实验伤害人民”成为能够理解的现实。

她也不是只负责等待救援。她对节庆的投入、对草神的信任和对生活的主动选择，都在推动剧情。可以借鉴的是她与核心问题之间的因果关系，而不只是病弱人物带来的情绪效果。

### 3. 让主角拥有别人无法替代的见证责任

树王被删除后，旅行者的独特性不只体现为力量或身份，而是仍然记得一场无人能够共同确认的告别。

这使“寻找真相”多出一层伦理意味：真相不一定能立刻获得公共承认，也未必适合被轻率地重新塞回所有人的记忆，但见证者仍需知道自己经历过什么。

### 4. 区分解释、洗白与承担

散兵受到操控的事实，使其过去变得更复杂；剧情随后却没有停在“原来他也很可怜”。删除失败、记忆恢复和承认受害者追究权，继续把故事推向责任。

这类写法的价值在于同时保留两个判断：一个人可以确实受过伤害，也确实需要为自己的行动负责。

### 5. 信息密集的故事，需要清楚区分揭示层级

须弥多次让角色根据当时线索提出假说，再用新证据修正。树王变小与纳西妲起源、散兵的三次背叛、沙漠对旧神关系的认识，都属于这一结构。

写作时应明确哪些是人物相信的解释，哪些是后来确认的事实。否则读者容易把中途猜测当成最终设定，也会把悬念误读成前后矛盾。

与《往世乐土》相比，须弥同样把记忆与人格联系起来，但更强调记忆的删除如何改变公共叙述，以及一个人是否愿意重新接受不光彩的过去。

## 八、供《憨之轨迹》讨论的借鉴方向

以下仅为候选方向，尚未采纳。

| 可讨论方向 | 可以借鉴的结构 | 需要避免的问题 |
|---|---|---|
| 通过重复制造认知变化 | 相似场景保留少量差异，让人物逐步发现异常 | 只重复流程，没有新的关系或理解 |
| 让小愿望连接大危机 | 一个普通人的目标直接受到核心制度影响 | 配角只作为惨剧工具，没有主动选择 |
| 给知识设置来源与权限 | 人物获得不同信息，因此形成不同判断 | 为制造反转任意隐瞒读者应当知道的事实 |
| 保留唯一见证者 | 让记忆成为关系和责任，而非单纯谜题答案 | 用失忆随意取消既有情感和后果 |
| 让反悔落实为承担 | 人物承认真相，并接受他人不同的反应 | 通过悲惨身世要求受害者立刻原谅 |

如果毕业设计规模有限，更适合选择一个中心问题，例如“遗忘能否解除责任”，再用少量角色和一个可观察的物件完成表达。无需同时引入轮回、造神、世界树、国家阴谋和大规模历史改写。

## 九、阅读时需要保留的边界

- 花神诞祭轮回是集体梦境实验，不是物理时间不断倒流。
- 迪娜泽黛在轮回后获救，但魔鳞病要到污染根源清除后才治愈。
- 正机之神战斗的 168 次演算，不等于已确认的节庆循环次数。
- 赤王时代的禁忌知识危机，与五百年前灾变应分别叙述。
- 树王早年变小，不等于纳西妲在那时诞生。
- 删除树王后，旅行者保留记忆，纳西妲与派蒙等人的相关记忆和记录被改写。
- 纳西妲交换两颗神之心的条件不同；博士并未因此全部消失。
- 散兵删除自身没有复活受害者，也没有取消已经造成的伤害。
- 恢复散兵个人记忆，不等于恢复全世界对他的记忆。
- 本文不借后续版本补答降临者、神秘声音等在当时仍未揭晓的问题。

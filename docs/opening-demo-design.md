## 2. 已有确认基线

### 章节推进与区域探索（2026-10-19 确认）

- 整体采用**章节推进＋小区域自由探索**。玩家在小区域中走动、观察居民和调查环境，主线按剧情推进；调查、对白与战斗在章节内连续衔接，不把每段事件拆成一次选关。
- 区域之间可以通过道路、出入口与必要转场连接。具体路径、切换和返回规则由 D2-03 设计，不在本次指定场景加载技术或新增地图。
- 序章仍为外围道路、镇内街区两处小区域，两场 1V1、两个可任选调查顺序的必需调查点、一个可删环境点；返乡至开始赴塔、约 10～15 分钟的目标保留。家门与屋内对白如何对应两区域仍待设计，不自动增加室内探索地图。
- 本次选择着重探索的代入感，不增加开放大世界、跨区域自由选择主线或神使挑战顺序的制作范围。章节数量与划分、区域回访规则、后续地区与神使顺序仍待设计；神使统筹区域的设定不等于每个区域都已获得制作许可。
- 本次确认不代表修订话本、法师型第二战接入或 D2-02 全部通过。已有战斗、2.5D 镜头、角色旁菜单与鼠标／键盘各自完整操作要求保留；跨战斗资源与失败恢复仍由 D2-05 确认。

### 故事与角色（D2-01 当时版本，最新以《序章·归来》为准）

单个白色圆团毛怪返乡，沿以下顺序经历开场：

**外围广播 → 战士首战 → 小镇调查 → 恐惧退缩 → 憨努努触发当下醒悟 → 法师第二战 → 前往憨塔。**

- 广播由毛怪俱乐部面向全体居民发出，不是主角专属消息；广播草稿沿用设定文档。
- 主角起初怀疑是在整活，首战后亲眼看到小镇和居民的异常，才进一步确认广播属实。
- 邪祟放大恐惧与动摇；主角以“不在乎”说服自己退缩，再通过看见随身憨努努意识到自己真正想做什么。
- 醒悟发生在当下，不加入具体往事或回忆过场，不赋予玩偶独立驱邪能力，不设主角永久免疫。
- 开场的行动动机是“她帮助过我，我想去帮她”；更深的感情认识留在后续旅程，不直接定为恋爱线。
- 战士型与法师型是已确认的敌人定位，其具体外形、招式、台词和动作尚未定稿。

### 战斗与操作

- 两场均为单个毛怪对单个敌人的 1V1，不增加可操控队伍。
- 战前自由搭配四个普通技能与一个独立大招，攻击和物品不占技能槽；按速度形成可见行动顺序，直接选招执行。
- 卡点由各技能配置，漏按保留基础效果；敌方逐击闪避或精准格挡，成功免除对应击伤害，格挡恢复少量技力。红光对应击不可格挡，前一击失误不剥夺存活角色后续应对机会。
- 技力和大招能量独立；大招在当前完整行动结束后插入，保留原定正常行动。回血物品占用正常行动。
- 保留 2.5D 空间、角色旁菜单、目标预览／确认／取消、阶段镜头和动作附近的提示。
- 鼠标和键盘均能独立完成操作，也可混用。原型数值、窗口和测试能力仍是试玩配置，不因复用而成为正式设定。

## 3. 本次确认：体验目标与起止

**推荐方案已获批准：两处小区域、两场 1V1、约 10～15 分钟的完整开场。**

玩家应经历“返乡时不相信 → 亲眼看到衰败 → 害怕退缩 → 决定去帮憨”的变化。调查让玩家主动确认处境，第二战让刚作出的决定落实为行动，结尾由玩家开始走向憨塔。

操作目标是理解基础选招与确认、技能卡点的奖励性质、逐击应对和红光限制，并接触资源选择与大招。无需完美操作才能通关，也不以背熟全部技能说明作为开始条件。

- **起点：**主角刚回到小镇外围，在返乡道路获得控制；不制作旅行前史。
- **终点：**法师战后恢复控制，玩家走向镇外道路，镜头给出憨塔方向，结束演示；不进入塔内。
- **空间：**外围道路、镇内小街区两处探索区域。战斗使用对应地点的简化舞台，共用战斗与镜头结构；结尾道路过渡不扩成第三处探索区域。
- **憨塔表现：**仅作为远景与目的地方向，不在本次确定完整建筑或与城堡的空间关系。
- **时长假设：**首次阅读、正常思考、不含失败重试和长时间研究装配。10～15 分钟是待 D3 试玩检验的目标，不是实测结果或硬性计时限制。

| 环节 | 玩家经历与体验用途 | 建议时长 |
| --- | --- | --- |
| 外围广播 | 走近小镇触发最后广播，看到主角“可能在整活”的反应；建立反常处境 | 1～2 分钟 |
| 战士首战 | 遭袭进入第一场 1V1；理解选招、确认目标、技能保底和逐击应对 | 2～3 分钟 |
| 小镇调查 | 自由走动，主动调查居民和环境，确认广播属实 | 2～3 分钟 |
| 退缩与醒悟 | 主角朝来路退几步，看见随身憨努努，完成已认可的独白与行动决定 | 1～2 分钟 |
| 法师第二战 | 面对不同攻击节奏，检验应对、资源选择和大招使用的理解 | 3～4 分钟 |
| 前往憨塔 | 战后由玩家走向道路，看到目的地方向，收束演示 | 约半分钟 |

超时优先删重复说明和等待，不压缩醒悟的因果过程。

## 4. 本次确认：必做、可删与不做

### 必做

1. 两处小型探索区域和按剧情顺序发生的两场 1V1；两次战斗间保留完整调查、退缩与醒悟过程。
2. 镇内两个必需调查点，顺序可自由选择：一个居民已难以回忆憨；另一处居民仍习惯性祈祷或等待，却缺少情绪回应。两处均调查后触发退缩，承担不同叙事作用。具体居民身份与对白在 D2-02 设计。
3. 提供可直接使用的默认装配，同时保留自由搭配入口；不强迫新玩家先读完所有技能说明。具体候选池、默认组合及换装时机在后续任务确定。
4. 分段教学：首战提示基础操作；第二战侧重独立运用、红光与连击辨识，并提供自然体验大招的机会。提示时机、敌人招式与资源条件分别由 D2-02、D2-05 确定，不在此假定必定攒满能量。
5. 清楚的当前目标、对话推进、暂停和失败恢复。恢复方式须在 D2-05 明确，不直接继承旧卡牌版整关重开或独立原型每战重置。
6. 鼠标和键盘各自支持探索、调查、对话、装配、战斗、重试与结束页的完整流程。探索键位及交互方式在 D2-03 确定；战斗不擅自增加自由走位。
7. 最后一次战斗结束后恢复控制，由玩家开始前往憨塔，再结束 Demo。

### 可删

- 一个可选环境调查点，暂以停摆的店铺为例；补充小镇失去生机的感受，不提供推进主线所必需的信息。具体对象仍可在后续设计中调整。
- 重复居民对白、额外路段、复杂天气和额外镜头演出。
- 压缩时先删上述内容；主线七个环节、两个必需调查点、两场战斗和失败恢复保留。

方案比较：约 8～10 分钟的引导式版本会减少玩家亲自调查的空间；15～20 分钟版本需要更多环境内容。当前选择 10～15 分钟的小范围探索版；后续若改变核心边界，应重新确认范围。

### 不做

- 憨塔内部、第三场战斗、毛怪守卫、最终战以及整条主线的制作。
- 支线任务、分支结局、室内地图、群战和战斗自由走位。
- 成长、信物获取、商店和完整存档系统。必要的失败与剧情进度恢复仍属于必做，其边界由 D2-05 决定。
- 正式配音和整套正式美术生产。
- D2 内制作整体 HTML Demo、创建 Unity 工程或生成正式资源。D2 交付设计与清单，D3 制作 HTML，D4 再进入 Unity 样片。

## 5. 验收与验证边界

### D2-01 设计验收

- 起点、终点、区域数、战斗数、调查点数量和必做／可删／不做边界明确。
- 每段有玩家行为与体验目的；剧情顺序、主角动机和既有战斗规则没有被新提案覆盖。
- 新选择已与既有设定分开记录，关键边界获得用户批准；正式台词、技能、数值、美术和资源规则不被误标为已确认。
- 本任务完成代表范围设计完成，不代表 D2 全部完成或可玩体验已经验证。

### D3 实施后的验证计划（尚未执行）

1. 分别只用鼠标、只用键盘，从开始走到结束，覆盖装配、调查、对话、战斗和重试。
2. 检查两个调查点的顺序交换、重复交互和两场战败重试，确认不跳过必要剧情、不重复奖励、不出现流程卡死。
3. 让首次试玩者说清广播为何可信、主角为何退缩、为何改变决定、接下来去哪。
4. 检查玩家是否理解逐击应对、红光限制、漏卡点仍有效、大招不占正常行动；通过存在操作失误的试玩检查容错，不以全程完美操作作为唯一成功证据。
5. 记录每段耗时、停顿与理解困难，由用户确认整体节奏。若需压缩，按本文删减顺序处理。
6. 沿用战斗规则回归，对新增事件推进和恢复逻辑做必要验证；自动测试不替代对叙事、读招和手感的人工判断。

# 《空洞骑士：丝之歌》剧情总结与叙事参考

整理日期：2026-10-20  
用途：为毕业设计《憨之轨迹》后续的剧情讨论保留参考。  
范围：已发行本体的三幕主要故事、核心人物、可达成结局及必要支线，包含完整剧透；不展开战斗攻略，不把删减内容或未核实的扩展情节纳入正式故事。

## 1. 故事概览

大黄蜂离开圣巢的原因，是一次针对她血统与能力的绑架。押送途中，她逃离牢笼，跌落到陌生王国纺络的底部，开始向王国最高处追查。

沿途的虫民仍然相信山顶圣堡能够给予救赎，但维系这一信仰的体系早已崩坏。丝线穿过城市、机器与虫民的身体，将他们联系起来，也使他们成为控制的对象。

大黄蜂逐渐发现，自己的编织者血统与这里的统治历史密切相关。随着她介入当地人的生活，旅程也从摆脱囚禁、查明真相，发展为主动争取这个王国的未来。

**贯穿本文的解读：一个被血统赋予用途的人，逐渐决定怎样使用自己的能力，以及哪些人值得她回头救助。**

来源：[官方 Steam 页面](https://store.steampowered.com/app/1030300/Hollow_Knight_Silksong/)、[大黄蜂的本作经历与对白](https://hollowknight.wiki/w/Hornet_%28Silksong%29)。

### 1.1 三幕之间的因果

| 阶段 | 当前目标 | 新发现带来的变化 |
| --- | --- | --- |
| 第一幕：进入纺络、向上攀登 | 摆脱绑架，追查圣堡及自己的处境。 | 朝圣者期待的乐园，与实际经历的危险越来越不一致。 |
| 第二幕：进入圣堡、面对统治者 | 找到丝线灾难的源头，理解编织者留下的体系。 | 打败源头后，如何处理其力量成为新的问题。 |
| 第三幕：返回深处、完成救援 | 处理捕获统治者之后扩大的危机。 | 大黄蜂需要重新理解自己的过去，并把救助具体落实到另一个生命身上。 |

第三幕只在通往它的路线中发生。不能把所有结局当作同一条连续历史，也不能把进入第三幕的阶段性结局直接当作一切问题已经解决。

## 3. 纺络为什么变成现在的样子

### 3.1 灵丝与编织者的起源

灵丝来到这片土地后，建立了自己的支配。编织者的起源与她的丝有关；原初罪者的回忆展示了原有生物被丝改变的过程。

灵丝把编织者称作自己的女儿，要求歌声与侍奉。后来，编织者反抗、让她沉睡，并试图在她仍然存在的情况下获得自己的自由。

来源：[灵丝的历史与对白](https://hollowknight.wiki/w/Grand_Mother_Silk)、[原初罪者的回忆和对白](https://hollowknight.wiki/w/First_Sinner)。

**理解边界**：原初罪者知道起源真相，也曾因背教被囚禁；具体哪一次行为直接导致她获罪，不能仅凭称号补出完整事件。

### 3.2 圣堡既是信仰中心，也是维持囚笼的装置

编织者设计了依靠歌声与祈祷维持的体系，使灵丝持续沉睡。圣堡的指挥者、建筑师与保管者分别承担统治、机械和知识管理等职能。

普通虫民未必知道歌声维系的真正对象。朝圣、服务与劳作，被组织成一个声称将永远延续的秩序。

来源：[圣堡的历史与职能](https://hollowknight.wiki/w/The_Citadel)。

**解读**：世界观通过空间和生活结构被呈现。谁住在高处，谁留在工厂，谁掌握知识，谁必须不断工作，都在说明这个王国怎样运转。

### 3.3 用来延续生活的丝，也成为控制的通道

圣堡曾使用丝延长虫民的生命。经过漫长时间，丝与许多虫民的身体深深结合。

当灵丝通过这些丝重新施加影响，虫民便容易被侵扰。许多被控制者仍重复原来的行为，却失去了自主判断；熟悉的工作与仪式因此变得异常。

来源：[Haunting 的成因与表现](https://hollowknight.wiki/w/Haunting)。

**解读**：灾难与社会原本依赖的技术存在因果关系。玩家理解灾难时，也在重新理解这个文明曾经追求的延续方式。

### 3.4 编织者留下了未完成的出路

一些编织者离开纺络，另一些留下工具、符文、尝试与遗愿。她们曾努力寻找摆脱灵丝的方法，却没有完成彻底的解脱。

大黄蜂因此同时面对两个方向的期待：统治者需要她的力量，前人也希望她完成自己未能完成的事情。

来源：[编织者相关记录](https://hollowknight.wiki/w/Weavers)。

**解读**：血统在这里既是能力来源，也是他人加在主角身上的用途。主角成长的重要部分，是逐渐辨认哪些期待应当回应，哪些应当拒绝。

## 4. 三幕主线：从寻找出口，到主动返回

### 4.1 第一幕：牢笼打开，旅程开始

大黄蜂被来自纺络的蒙面虫带走。运输途中，丝蝇破坏牢笼上的符文，她挣脱并坠入苔穴。

她开始沿朝圣路线向上，寻找把自己带来的原因。骨底镇、沿途聚落与朝圣者，使王国首先以具体生活进入她的视野。

来源：[大黄蜂的开场经历](https://hollowknight.wiki/w/Hornet_%28Silksong%29)、[纺络背景](https://hollowknight.wiki/w/Pharloom)。

**解读**：开局动机明确而有限。主角先有理由探索，再逐渐形成对地方与居民的责任。

### 4.2 与蕾丝相遇：对手的轻快外表之下存在敌意与不安

蕾丝拥有鲜明的姿态、笑声与战斗欲望。她阻挡大黄蜂继续登高，也以自己的方式谈论上方的痛苦与危险。

随着冲突发展，她越来越担心母亲更需要大黄蜂。她对主角的敌意，逐渐与自身是否被需要的问题连接起来。

来源：[蕾丝的相遇、对白与动机](https://hollowknight.wiki/w/Lace)。

**理解边界**：蕾丝与丝蝇的联系、她对坠落的谈话，为开场提供了推测空间；不据此直接认定她策划了全部逃脱过程。

### 4.3 第二幕：朝圣终点暴露了内部结构

进入圣堡后，大黄蜂发现的并非朝圣者想象中的完美归宿。华丽建筑、劳作场所、医疗设施与遗留档案共同揭示统治的成本。

通往顶部的三重旋律，与圣堡内部的权力分工相关。向上接近核心，也意味着理解此前被遮蔽的运行方式。

来源：[圣堡与三重旋律](https://hollowknight.wiki/w/The_Citadel)。

**解读**：章节目标可以同时推进空间与信息。玩家每接近一个目的地，也应更清楚目的地为何存在。

### 4.4 面对灵丝：捕获大黄蜂的原因得到解释

灵丝寻找具有编织者血统、能够产生丝的后裔。大黄蜂被带来，正因为她具有这种力量。

抵达摇篮圣所后，大黄蜂击败蕾丝，并接近灵丝。胜利之后，她可以束缚并承接灵丝的力量，也可以沿另一条路线使用准备好的陷阱。

来源：[灵丝的捕获行动与本作事件](https://hollowknight.wiki/w/Grand_Mother_Silk)。

**解读**：主角到达最初目标后，剧情把问题推进了一步：知道谁造成了困境之后，还必须决定怎样结束这种困境。

### 4.5 灵魂陷阱：一次胜利产生了未预见的后果

在“灵丝与灵魂”路线中，大黄蜂在帮助居民、建立联系之后，与看护者等人合作准备陷阱。

陷阱借助虚空，把灵丝向深处拖去。灵丝抓住大黄蜂，蕾丝出手切断束缚，使大黄蜂脱离险境，自己却和母亲一起坠落。

来源：[任务“灵丝与灵魂”](https://hollowknight.wiki/w/Silk_and_Soul)、[蕾丝在陷阱发动时的行动](https://hollowknight.wiki/w/Lace)。

**解读**：蕾丝同时具有反抗母亲、怨愤与解救主角的行动效果，不宜把复杂动机压缩成单一的温柔或嫉妒。

### 4.6 第三幕：问题没有随统治者坠落而结束

陷阱并没有立刻使王国恢复。灵丝在深处结茧抵御虚空、保护蕾丝；虚空顺着她遍布王国的丝扩散，形成新的灾难。

大黄蜂向参与陷阱的蜗牛萨满追问，并决定继续处理局势。她已经与这片土地建立联系，也不愿再旁观一个王国衰亡。

来源：[蜗牛萨满的第三幕对白](https://hollowknight.wiki/w/Snail_Shamans_%28Silksong%29)。

**解读**：英雄行动的后果被纳入故事。主角的责任通过继续面对后果表现出来，这使第三幕成为前两幕选择的延伸。

### 4.7 古老力量与赤红忆境

为深入虚空，大黄蜂寻找纺络旧日力量留下的心脏，让萨满能够施展进入记忆的仪式。

这些力量提醒玩家：这片土地拥有不止一种历史，当前统治者没有创造这里的一切。

来源：[古老心脏与仪式说明](https://hollowknight.wiki/w/Snail_Shamans_%28Silksong%29)。

在赤红忆境中，大黄蜂重访与赫拉、蜂后维斯帕及白夫人有关的成长记忆。围绕她的期待曾包含守护、能力与身份；她现在能够以自己的理解回应这些期待。

来源：[赤红忆境及对白](https://hollowknight.wiki/w/Red_Memory)。

### 4.8 从过去带回能够行动的力量

大黄蜂从记忆中取得永绽花，并通过自身的丝使它显现。花的力量能够抵御虚空，让她继续向深处前进。

来源：[永绽花的来历与作用](https://hollowknight.wiki/w/Everbloom)。

**解读**：回忆既补足人物经历，也改变当前行动的可能。叙事中的过去因此能够参与高潮，而非只解释已经发生的伤痛。

### 4.9 最后要带走的是一个具体的人

大黄蜂在深处面对被虚空控制的失心蕾丝。她击败对方，解除虚空对其的控制，并抱起蕾丝准备离开。

灵丝将剩余的丝交给大黄蜂，帮助她带着蕾丝上升，自己则留在深处。

来源：[失心蕾丝的图鉴与结局事件](https://hollowknight.wiki/w/Lost_Lace)。

随后，永绽花的保护不足以支撑完整脱离。小骑士及虚空中的手足出现，将二者送回安全之处。蕾丝醒来，二人获得了离开旧有关系结构之后继续存在的可能。

来源：[结局“Sister of the Void”演出记录](https://hollowknight.wiki/w/Endings_%28Silksong%29#Ending_4:_Sister_of_the_Void)。

**解读**：宏观的解放，在最终画面中落实为救回一个曾与自己为敌的人。这个行动也给蕾丝留下了重新理解自身的空间。

## 5. 重要关系：创造、控制与承认

本节为基于情节的分析，不替代人物对白中的明确事实。

### 5.1 大黄蜂与他人赋予的身份

公主、守护者、编织者后裔、可以利用的力量，这些身份从不同方向作用于大黄蜂。

她既不能简单摆脱自己的来历，也逐渐能够决定怎样回应它。她的主动性体现在判断、拒绝和行动之中。

### 5.2 蕾丝对认可的渴望

蕾丝是被创造出来的生命。她对自身脆弱和是否被需要的疑问，使大黄蜂的出现带来强烈威胁。

这条弧线值得关注的部分，是人物可以同时具有攻击性和需要理解的伤口。理解动机并不要求抹去她曾经的危险行为。

### 5.3 灵丝的最后行动不能抹去此前的统治

灵丝在最终阶段保护蕾丝、提供逃离所需的丝。这让她拥有更复杂的情感表现，但并没有取消她支配虫民的事实。

角色可以在某一段关系里作出真实的关切，同时仍需面对其造成的伤害。

### 5.4 可选补充：伊娃的存在困境

伊娃由编织者创造，却无法轻易离开维系生命的结构。她希望获得自由，也帮助大黄蜂理解自身变化；在相应支线中，她请求与大黄蜂结合，以另一种方式离开长久的禁锢。

来源：[伊娃的背景与对白](https://hollowknight.wiki/w/Eva)。

**解读**：这条支线从另一个角度追问创造者与造物的关系，也让“结合”“延续”“自由”具有不止一种表达。它属于可选补充，不要求所有路线都经历。

## 7. 故事主题与叙事安排

以下均为本文解读。

### 7.1 用上下方向组织剧情认识

向上代表追查、朝圣和接近统治中心。进入第三幕后，向下又成为面对后果、寻找根源和救回他人的行动。

空间方向因此能够参与人物变化，而不仅用于区分关卡。

### 7.2 让环境展示同一制度的不同成本

居民、朝圣者、工厂、病房、档案与高层建筑共同构成一个社会。不同空间展示的差异，使“永恒秩序”成为可以被看见和质疑的东西。

借鉴时可以先问：一个设定会怎样影响普通人的住处、工作、日常语言与期待？

### 7.3 同一种力量可以产生不同关系

丝可以束缚、控制，也可以连接、保护和保存记忆。它在不同角色手中产生不同后果。

这种安排能让核心意象持续参与故事。主题通过多次使用同一种事物逐渐展开，而不必完全依赖说明性的对白。

### 7.4 主角对地方的责任需要形成过程

开场的大黄蜂有明确的个人问题。沿途的帮助与交流，使她对纺络的关切逐渐具体。

后期承诺能够被前期行动支持时，玩家更容易理解主角为何愿意继续留下。

### 7.5 对手可以在最后成为救助对象

蕾丝与大黄蜂的关系经历敌意、较量、复杂的相救，以及最终被带离困境。

这种变化需要保留此前冲突的痕迹。救助具有重量，正因为对象曾经难以接近，双方也并未从一开始就互相信任。

### 7.6 回忆需要改变当下的决定或能力

赤红忆境同时回答了身份问题，并为最后的行动提供条件。

对创作而言，可以检查：如果删去这段回忆，主角当前的判断、关系或行动是否真的会不同？若没有变化，这段回忆可能仍停留在资料补充层面。

### 7.7 留白与主线因果需要分别处理

结局的象征意义可以开放，具体事件之间的关系仍需让人看懂。

例如陷阱为何导致新危机、主角为何再次深入、最后要救谁，属于必须清楚的行动因果；某些神秘存在的全部来源，则可以保持未解。

## 8. 与其他参考作品的联系及借鉴方向

| 参照对象 | 可以一起研究的问题 |
| --- | --- |
| 《空洞骑士》 | 同一系列如何分别通过沉默主角与会明确表达意见的主角，建立身份与责任。 |
| 《雨世界》 | 一个仍在运行的旧体系，如何同时提供生存条件和制造新的困境。 |
| 往世乐土 | 过去的记忆如何帮助当前人物行动；被留下的生命如何争取自己的选择。 |
| 《原神》稻妻 | 对长久秩序的追求，如何与具体生命的变化发生冲突。 |
| 匹诺康尼 | 看似能够庇护众人的体系，是否仍然尊重其中每个人的意志。 |

这些是跨作品的阅读问题，不表示各作具有相同设定或相同答案。

### 留给《憨之轨迹》的讨论素材

- 主角的私人目标，能否随着具体相处逐渐变成对某个地方的关切？
- 关键的道具或能力，能否在不同人物手中体现不同的关系？
- 旧故事中的受害者或对手，是否仍然拥有作出新选择的空间？
- 若安排一次回忆，能否让它改变当下的行动，而非仅用于解释过去？
- 结局能否以一个具体的相救、告别或同行动作，表达宏观主题？

以上均未确定为正式剧情。需要结合毕业设计的角色数量、演出资源与篇幅继续筛选。

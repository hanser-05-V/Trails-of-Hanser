# 《憨之轨迹》主线剧情大纲 · 美梦篇

本文记录新版主线，从毛怪返乡写到憨塔决战。序章的场景和对白改写时，以本文明确的新设定为准。三章的具体故事、终战演出与尾声细节见文末待定项。

## 一、故事主题

游戏就像一个能让人暂时安放心愿的美梦。人在其中得到的安慰、陪伴和勇气，可以在离开之后继续帮助自己面对生活。故事通过人偶与主角的分歧来呈现这个主题。人偶看见毛怪们在梦里过得开心，于是相信只要让梦一直持续，就能一直保护他们。主角也理解美梦的吸引力，却认为毛怪有权决定自己何时离开，并把在梦里获得的力量带回自己的生活。

## 二、事件前史

1. **憨进入卡带空间。** 憨长期以 Hanser 的身份回应期待，逐渐感到自己的生活和偶像的职责纠缠在一起。银狼用卡带创造了一个可以独处的空间，憨暂时退到其中。她在情绪波动时反复思考「自己是自己，Hanser 是 Hanser」。人偶只接收到有偏差的信息，将它理解为自己应该接过「Hanser」这个身份，让憨能够安心休息。原话和人偶实际收到的内容留待写对白时确定。
2. **人偶接替 Hanser。** 起初它认真回应毛怪的请求，希望把偶像的职责做好。请求不断累积，机体出现故障。与此同时，它也开始渴望拥有人的感情，并怀疑毛怪们喜欢的是自己，还是「Hanser」这个名字。它想拥有一颗「心」，却越来越依赖自己可以控制的回应。
3. **美梦机器介入小镇。** 人偶建造机器，让毛怪的意识进入自己喜欢的世界。梦确实给部分居民带来安慰，但人偶随后用「神之声」将他们逐步留在其中，调用他们的意识作为算力，维持自身的运转。它也越来越相信，任由居民回到原来的生活，只会让他们重新受苦。这份保护欲与它对算力和认可的需求叠在一起，使控制不断加深。
4. **三位神使封印人偶。** 三位神使发现居民正在失去自主判断，耗去大部分力量，将人偶封在憨塔主殿。她们各自守住一道封印和一片区域。封印暂时压制人偶的力量，小镇里的侵蚀仍在持续。主角抵达时，三道封印已经在松动，神使自身也在逐步被侵蚀。

## 三、梦泡、神之声与封印

| 设定 | 剧情规则 |
| --- | --- |
| 小镇的大梦泡 | 整座毛怪小镇位于同一个大梦泡的影响范围内。三章分别发生在这张地图上的三个区域，每个区域有自己的故事和关底神使。居民的身体仍留在小镇，受到深度侵蚀的意识会被拉进美梦。 |
| 神之声 | 人偶施加在意识里的语言暗示，听来像在心里浮现的话。暗示由诱导逐渐变成命令，居民一步步失去独立判断。它与满穗通过镇上设备发出的广播是两件事。 |
| 居民的变化 | 整体从入迷走向痴狂。严重时，身体像失去灵魂的躯壳，听从内心的声音行事。有的居民会发生争斗，有的会因过度消耗而倒下。各阶段的具体表现和对应事件待定。 |
| 梦境守卫 | 大梦泡从一开始就把满穗判定为违反梦境规则的存在。广播使她的位置暴露后，大梦泡生成守卫追踪她，试图抹去她这缕意识。 |
| 三道封印 | 封印无法修复。每解除一道，人偶的侵蚀都会加重，主角也会离主殿更近一步。三枚信物是开启主殿的钥匙。继续等待同样会让封印衰败，进入主殿处理源头是满穗提出的办法。 |

「从梦中醒来」用于决战对白，指居民摆脱「神之声」并重新掌握自己的身体和选择。居民在梦里的经历可以在离开之后影响他们的生活。

## 四、序章 · 归来

1. **毛怪赶在通道关闭前返乡。** 满穗正在封闭小镇与外界相通的通道，主角恰好在关闭前进入。刚返乡的他还保有独立判断，是满穗此时能够求助的人。
2. **广播暴露满穗的位置。** 毛怪在返乡途中听到广播。满穗试图用广播提醒居民察觉异常、抵抗心里的指令。守卫循迹追来，主角遇见正在逃避追杀的满穗，并出手救下她。首战的对手是梦境守卫。
3. **毛怪自行确认小镇的异常。** 脱险后，满穗先说居民正受到控制。毛怪一时难以相信，便去镇上找熟悉的居民问话，见到侵蚀程度不同的表现。亲眼确认之后，他主动回去问满穗该怎么办。
4. **满穗提出前往憨塔的办法。** 她说明人偶、三位神使和三道封印的关系，告诉主角封印已经无法修复，并请求他依次探索神使所在的区域，取得三枚信物，进入主殿。毛怪明白路上会有风险，仍决定出发。

**作者掌握的伏笔。** 玩家认识的「满穗」是憨的一缕意识。她有时会化成不同角色与居民交流。人偶开始侵蚀小镇后，她无法回到卡带空间里的本体，也没有足够力量正面对抗人偶。她清楚自己的来历，但在决战前无法向主角说明。对玩家而言，她始终以满穗的身份指路和求助。满穗本人没有战斗关卡。她无法坦白身份的具体原因暂不展开。

## 五、三片区域与三位神使

三章按固定顺序推进。每一章发生在小镇地图的一片区域，由一位神使守护。该神使是本区域梦境故事的主人，也是这一章的关底 Boss。

1. **探索区域。** 主角先见到本地居民受侵蚀的处境，再逐步了解这片区域及其神使的故事。每章具体发生的事待定。
2. **挑战神使。** 守印神使受到侵蚀，在关底阻拦主角。她们在各自关卡的战后对话中交代最重要的信息和托付。
3. **获得信物。** 被击败的神使短暂恢复判断，主动交出信物。她们的力量已经不足以继续行动，随后沉睡在各自的信物里。三位神使只在最终决战再次出现。
4. **承担解封的后果。** 随着一道道封印解除，小镇的控制加深。主角在继续前进的路上能看到居民的状态变坏。拿齐三枚信物后，他才得以进入憨塔主殿。

## 六、憨塔主殿与结局

### 决战的两层冲突

- **该怎样保护毛怪。** 人偶相信，美梦给了居民想要的生活，而现实中的困难依旧存在。既然机器能维持梦境，它便质问主角为什么一定要结束它。主角承认梦中的安慰和勇气有价值，并指出居民应该保有离开美梦的选择。离开之后，他们仍然可以用在梦里获得的力量面对生活。
- **人偶想以什么身份被记住。** 人偶最初替憨承担职责，到最后已经想知道，毛怪是否会愿意认识作为自己的它。主角可以肯定它曾经认真对待过毛怪，也指出现在的控制正在伤害他们。只要人偶还在控制他们，就无法知道谁愿意主动留下。这层心结与关停机器的选择相连，具体对白留待终章编写。

### 决战对白草案

**人偶**

> 只要这台机器还在转，毛怪们就能留在自己喜欢的世界里。回到镇上，他们原来过不去的坎还在。既然在这里能过得开心，一直留下来有什么不好？

**主角**

> 总有一天，我们会从梦中醒来。回去以后，日子也许还是一样难过。可我在梦里得到的那一点勇气，我想带回去。有些以前不敢做的事，我想亲自试一次。他们想怎么过自己的日子，也该由他们自己决定。

### 决战收束

三位神使在决战中从信物里再次现身，满穗作为憨的一缕意识的身份也在此时揭开。收束方向是人偶亲手关闭美梦机器，结束「神之声」对居民的控制，随后消失。它最后的主动选择，把决定如何生活的权利交还给毛怪。小镇居民重新面对自己的生活，尾声可从中选择一个具体变化，回应主角关于梦中勇气的那句话。人偶消失的具体机制、神使怎样参与决战，以及憨本体之后的去向留待确定。

## 七、旧序章衔接与后续待定

### 改写旧序章时需要接顺的地方

- **广播与通道。** 改为满穗借广播提醒居民抵抗控制。毛怪在通道关闭前进入，广播内容需与封闭后的处境相符。
- **守卫与战后处理。** 首战追兵采用大梦泡生成的守卫。战后剧情重点放在脱险、对话和居民调查，删去旧稿里满穗净化卫兵或居民的情节。
- **满穗、魔导盘与信物。** 旧序章中的赠礼、拟态和初始能力可在改写时逐项衔接。满穗的来历按本版伏笔处理。三位守印神使交给主角的是开启主殿的三枚信物，和旧序章道具的关系另行确定。
- **出发目标。** 从旧稿里先尝试联系真正的憨，改为在满穗请求下探索三个区域、取得信物并进入主殿。第一次对话交代受控现象，调查确认后再引出三道封印。

### 待定事项

1. **三章与神使。** 确定三位神使名单、地区、固定顺序、各章故事，以及每位神使阻拦主角和战后交出信物的具体缘由。
2. **封印与城镇变化。** 明确封印能压制人偶到什么程度、留存的侵蚀如何继续，以及每次解封后玩家会看到哪些变化。
3. **满穗与终战。** 补写身份伏笔、揭露时机、三位神使现身后的作用，以及主角如何从亲历中说出自己在梦里得到过勇气。
4. **人偶与尾声。** 细化信息误传的内容、人偶主动停机与消失之间的因果，以及憨本体的去向和居民回归生活后的具体片段。

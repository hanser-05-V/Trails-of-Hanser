# 《崩坏3》往世乐土剧情总结与叙事参考

整理日期：2026-10-20  
用途：为毕业设计《憨之轨迹》后续的剧情讨论保留参考。  
范围：往世乐土独立剧情及主线第29—31章的主要故事、人物关系、主题与叙事安排，包含结局剧透；玩法仅在理解故事所必需时提及。

> **当前讨论背景**：用户已将《雨世界》与《崩坏3》往世乐土列为剧情研究对象，希望为自己的游戏积累参考。对往世乐土最喜欢的具体人物、情节与主题，尚未逐项确认。
>
> **阅读约定**：原作情节与本文解读分别标明。“借鉴方向”属于后续讨论素材，尚未成为《憨之轨迹》的正式设定。本文聚焦乐土篇，不把《崩坏3》后续所有宇宙观解释、角色经历或衍生作品混入本篇梳理。

## 1. 故事概览

雷电芽衣来到一个失败文明留下的记忆空间，寻找关于崩坏、律者与前文明的答案。

在那里，她认识了十三英桀的记忆体。那些原本只属于历史与传说的人，逐渐成为会与她聊天、开玩笑、发生分歧，也会为她作出选择的朋友。

随着往事被揭开，芽衣得知爱莉希雅的真实身份，以及她曾为未来付出的代价。随后，侵蚀之律者威胁到整个乐土，英桀们的记忆也面临消失。他们共同为芽衣争取机会，为自己的故事完成最后一次告别。

**贯穿本文的解读：过去的人把希望交给未来，未来的人则让他们知道，那些选择仍然产生着影响。**

### 1.1 阅读范围与名称

| 名称 | 本文中的含义 |
| --- | --- |
| 往世乐土 | 保存英桀记忆体的空间，也是独立剧情系统的名称。 |
| 往世乐土独立剧情 | 芽衣逐步认识英桀、面对梅比乌斯与阿波尼亚等人的考验、接近爱莉希雅秘密的前半段故事。 |
| 永世乐土 | 与爱莉希雅密切相关的更深层记忆空间，是后续主线的重要舞台。 |
| 乐土篇 | 本文对以上连续故事的统称，涵盖独立剧情与主线第29—31章。 |

资料：[永世乐土资料页](https://honkaiimpact3.fandom.com/wiki/Elysium_Everlasting)。该页面为社区整理，用于辅助确认篇章关系；关键情节以正文所列游戏文本为主。

### 1.2 两条时间线

| 时间线 | 主要内容 | 芽衣与它的关系 |
| --- | --- | --- |
| 前文明的历史 | 英桀们生活、战斗、经历失去；爱莉希雅作出最后的选择；文明最终未能抵挡终焉。 | 芽衣逐渐了解已经发生的事情。 |
| 乐土中的现在 | 记忆体与芽衣相遇；侵蚀危机出现；众人作出新的决定，完成乐土的谢幕。 | 芽衣直接参与，并成为结果的一部分。 |

**解读**：历史结局已经确定，但当前故事仍然具有行动空间。知道前文明失败，并不等于知道这些记忆体接下来会怎样选择。

## 2. 故事发生的前提

### 2.1 一个未能取得最终胜利的文明

在芽衣所属的文明之前，人类已经经历过一次与崩坏的漫长对抗。

前文明建立了逐火之蛾，发展技术，并通过融合战士等方式争取生存。十三英桀是理解那个时代的重要人物，但他们没有迎来拯救所有人的结局。前文明最终失败，幸存者、遗产与延续文明的计划，将影响留给了后来的人。

**解读**：乐土的情感基调来自这种已知的失去。读者逐渐接近的，是一群曾经努力生活、努力作战，却未能保住所属时代的人。

### 2.2 记忆体与现实本人必须区分

乐土中的英桀是记忆体。他们保留了与本人相关的记忆和人格，也能够在乐土里与来访者交流、产生新的经历。

因此，阅读时需要区分：

- 前文明时期的本人经历。
- 保存在乐土中的记忆及其覆盖范围。
- 记忆体在芽衣到来之后作出的新选择。
- 现实中的幸存者在乐土之外的后续经历。

不能将乐土谢幕直接理解为“十三人的现实身体在此刻一起死亡”，也不能把现实中的凯文与乐土中的凯文视为同一个行动主体。

**解读**：记忆体的存在形式，使故事能够讨论身份、记忆和延续；而他们在危机中的自主行动，又让这些讨论具有实际的情节后果。

### 2.3 芽衣为何来到这里

芽衣此前为了保护琪亚娜加入世界蛇。她希望获得力量，也希望了解崩坏与律者的真相。

进入乐土时，她对英桀既有求知的愿望，也保留警惕。她尚未把这里当作归属，更没有预料到自己会与这些记忆体建立深厚联系。

爱莉希雅热情地迎接她，以轻松的交流和引导，使这个陌生空间逐渐变得可以亲近。

来源：[游戏文本《初入乐土》](https://www.bh3text.com/dialog/er/1/初入乐土)。

## 3. 十三英桀：先认识人，再理解称号

下面以各自的重要矛盾概括人物，便于阅读群像。这是本文的理解入口，并非完整人物传记，也不用于排列实力或评价高低。

| 人物 | 理解这个人物的一个入口 |
| --- | --- |
| 凯文 | 被寄托救世希望的人，也背负着无法挽回的失去。 |
| 爱莉希雅 | 热爱人类、主动连接同伴的少女，仍会担心自己的身份不被接纳。 |
| 阿波尼亚 | 能看见命运，试图干预悲剧，却反复感受到改变的困难。 |
| 伊甸 | 珍惜艺术、文明与美，也承受着所属时代的落幕。 |
| 维尔薇 | 通过机械、魔术和不同思维分区展现才能，自身同样是一道谜题。 |
| 千劫 | 暴烈、难以接近，内心却存在无法轻易割舍的牵挂。 |
| 苏 | 温和的医者，持续面对救助、责任与代价之间的难题。 |
| 樱 | 身处残酷任务之中，亲情是她重要的精神支撑。 |
| 科斯魔 | 想成为英雄的少年，力量也使他越来越难接近普通生活。 |

| 华 | 经历失去与迷惘的年轻战士，仍在寻找值得坚持的道路。 |
| 帕朵菲莉丝 | 想吃饱、晒太阳、过安稳日子的普通人，也被放进了英雄的位置。 |

### 3.1 群像依靠关系成立

**解读**：十三英桀的吸引力，除了个人经历，还来自他们之间的相处。

朋友会记得彼此的习惯，战友会对同一段历史给出不同回应。人物在别人面前表现出的态度，有时比自我介绍更能说明性格。

这些交流使人感到：即使芽衣不在场，这群人也有自己的生活与关系。芽衣逐渐加入其中，玩家也随她认识这个群体。

### 3.2 不把所有人物归纳成同一种英雄

**解读**：英桀对生存、责任、他人和未来的理解并不完全相同。他们可以怀疑、畏惧、自私、固执，也可以在某一刻愿意承担代价。

群像因此需要保留差异。若只留下统一的崇高宣言，帕朵、梅比乌斯、凯文等人的不同选择就会失去各自的重量。

## 4. 前文明往事：爱莉希雅的秘密与告别

### 4.1 她从诞生起就是律者

爱莉希雅并非在故事末尾才突然成为律者。她是一位比编号所暗示的时间更早出现、从诞生起就具有这一身份的存在。

游戏通过她的童年与旅行呈现她如何认识人类。人们接纳并抚养了她，她也对世间的生活产生感情。她的名字与童年读过的乐园故事有关。

来源：[游戏文本《少女初成》](https://www.bh3text.com/dialog/mainline/1/31/31-12-1)。

**解读**：这段经历为她对人类的热爱提供了感情来源。她所珍惜的世界，由许多具体的相遇构成。

### 4.2 “第十三律者”需要放在叙事语境里理解

“第十三律者”包含了爱莉希雅为最后时刻安排的身份与说法，不能直接当作她真实诞生顺序的说明。

故事逐步修正一种过于简单的理解：她假扮共同敌人，让众人通过讨伐重新团结。这个说法没有涵盖她的全部意图，也没有涵盖同伴真正作出的回应。

她愿意承担那个名字，同时会害怕真实身份影响别人对自己的看法。她珍惜同伴，也期待他们能够理解自己。

来源：[游戏文本《告别之际》](https://www.bh3text.com/dialog/mainline/1/31/31-9-2)。

### 4.3 最后的宴会

爱莉希雅为自己的告别准备了一场宴会。凯文、伊甸、阿波尼亚和维尔薇成为到场的四位见证者。

有些人因信任她而拒绝讨伐；到场者也以自己的方式表达信任。到场与缺席不能简单对应支持与抛弃。

这场告别让爱莉希雅确认，身份的揭晓没有抹去共同生活形成的关系。她被同伴记住、理解，也被他们送别。

来源：[游戏文本《希望之门》](https://www.bh3text.com/dialog/mainline/1/31/31-10)。

**解读**：角色最担心失去的东西，最终由其他角色的行动给予回应。这里的感情来自相互确认，宴会则让这种确认获得了完整的表现形式。

### 4.4 她留给未来的可能性

爱莉希雅以自身消散为代价，尝试改变后世律者的处境，为保有人性、选择自身道路留下可能。

这份希望具有不确定性。作出选择时，她无法确认结果，也无法亲眼保证每一位后来者都会幸福。

在乐土中，芽衣既是律者，又保有自己的意志与情感。她的存在，使爱莉希雅终于得到来自未来的回应。

来源：[游戏文本《分别之前》](https://www.bh3text.com/dialog/mainline/1/31/31-12-5)。

**理解边界**：不要将这一贡献概括为“所有后世律者都会自动成为好人”。它没有取消后来者的挣扎、关系和自主选择。

## 5. 乐土中的现在：芽衣与英桀共同完成的故事

### 5.1 从接受引导，到重新判断引路人

芽衣逐渐发现，英桀并非没有秘密、没有私心的传承者。

梅比乌斯想借来访者实现离开乐土的目的，她的行动直接威胁芽衣。冲突结束后，芽衣对其他英桀的隐藏意图也更加敏感。

来源：[游戏文本《致世界上的另一个我·其五》](https://www.bh3text.com/dialog/er/2/致世界上的另一个我·其五)。

**解读**：这使历史人物拥有当前的欲望。来访者必须判断是否信任他们，人物关系因此能够持续变化。

### 5.2 阿波尼亚的预言与芽衣的选择

阿波尼亚以关于芽衣命运的预言设置试探。芽衣仍选择前往更深处，强调即使结果难以改变，也要亲自决定通向结果的过程。

阿波尼亚最终说明试探的性质，并允许她接近“第十三律者”的秘密。芽衣的回应，也使阿波尼亚想起曾经作出相似选择的爱莉希雅。

来源：[游戏文本《戒律，死生命定·其七》](https://www.bh3text.com/dialog/er/3/戒律，死生命定·其七)。

**解读**：芽衣在此表现出的意志，让她与过去产生联系。人物之间的相似性，为后面的理解与传承作了铺垫。

### 5.3 爱莉希雅消失，调查取代了原定的相会

进入永世乐土后，芽衣原本将进一步了解爱莉希雅的过去，却遭遇她的消失。英桀接连出现异常，熟悉的空间变得危险。

关于谁在行动、谁仍然可信的疑问，推动了后续调查。维尔薇的不同思维分区，以及“极恶”的行动，使局势更加复杂。

侵蚀之律者最终显露，成为对乐土的核心威胁。“极恶”的行动不应直接等同于维尔薇全部人格与意图。

来源：[游戏文本《所谓“意外”》](https://www.bh3text.com/dialog/mainline/1/31/31-2-2)。

### 5.4 侵蚀之律者威胁的是人的存在方式

侵蚀之律者能够利用记忆体的数据，吸收、控制并模仿他们。它以保存和延续为自己的行为辩护，也尝试模仿爱莉希雅与芽衣交流。

芽衣拒绝接受这些模拟对朋友的替代。她与英桀的相处，使她能够判断熟悉外表与真正意图之间的差异。

来源：[游戏文本《侵蚀之律者》](https://www.bh3text.com/dialog/mainline/1/31/31-2-1)。

**解读**：敌人的能力与舞台的性质相互配合。故事由此追问：保存一个人的资料、替他安排一个结果，与尊重他的意志有什么区别？

### 5.5 众人的行动相互衔接

英桀们为芽衣争取时间，保护恢复爱莉希雅的机会，同时阻止敌人继续使用他们的记忆。

侵蚀之律者试图通过其他英桀的记忆拼凑爱莉希雅，从而取得关键的删除程序权限。英桀们抹除、燃尽自身数据的行动，因此也具有阻断敌人计划的实际作用。

华使用羽渡尘，燃烧记忆；在记忆构成的世界里，这意味着付出自身的全部。

来源：[游戏文本《不负此名》](https://www.bh3text.com/dialog/mainline/1/31/31-8-4)。

**解读**：群像高潮需要行动上的配合。不同角色的付出共同改变局势，情感才能与因果关系结合。

### 5.6 帕朵：带着恐惧作出的决定

帕朵为凯文的攻击维持关键通路，却发现自己也将处在那一击经过的位置。

她想逃，想继续过平凡的生活，也努力说服自己没有必要留下。但最终，她返回通路前，伸出颤抖的手，维持了行动所需的机会。

她的恐惧没有消失，选择却已经作出。

来源：[游戏文本《引路人》](https://www.bh3text.com/dialog/mainline/1/31/31-8-3)。

**解读**：帕朵的日常愿望，使这段情节具有明确的情感代价。读者知道她想怎样活着，因此也知道她放弃了什么。她的动摇值得保留，因为动摇本身帮助人理解这次选择的困难。

### 5.7 芽衣成为记忆的承接者

芽衣与爱莉希雅相处形成的记忆，成为重现她的重要依托。伊甸等人保存的经历，又补足了芽衣未曾亲历的部分。

芽衣因此有机会理解一个更完整的爱莉希雅。她从寻求答案的来访者，变成愿意承接这些记忆、回应这些愿望的人。

来源：[游戏文本《告别之际》](https://www.bh3text.com/dialog/mainline/1/31/31-9-2)。

**理解边界**：这段情节有明确的记忆空间与人物行动前提，不宜归纳为“只要想念，任何人都能无条件复活”。

### 5.8 最后的相见与乐土谢幕

爱莉希雅再次面对侵蚀之律者。最终对话继续强调每个个体的独特性：芽衣有自己的人生，无须成为另一个爱莉希雅。

在最终的战斗与谢幕中，英桀们共同回应这场危机。侵蚀之律者被消灭，乐土走向终结，芽衣则带着经历返回现实。

来源：[游戏文本《终绝之战》](https://www.bh3text.com/dialog/mainline/1/31/31-13)、[官方动画短片《因你而在的故事》](https://www.bilibili.com/video/BV1fY4y1F7GL/)。

**解读**：故事为相遇保留了意义，也保留了告别的代价。传承体现在后来者继续生活、继续判断的过程中。

### 5.9 尾声：理解凯文，继续自己的道路

回到现实后，芽衣与凯文交谈。她更能理解他走到今天的原因，却仍不认同圣痕计划所代表的全部道路。

她最终离开世界蛇。凯文也确认，芽衣身上存在着爱莉希雅希望看到的结果。

来源：[游戏文本《第三十一章尾声》](https://www.bh3text.com/dialog/mainline/1/31/31-尾声)。

**解读**：传承没有要求主角放弃自己的判断。芽衣接过历史的重量，同时保留决定未来的权利。

## 6. 故事主题与叙事安排

本节为基于上述情节的分析，不代表官方创作说明。

### 6.1 把了解历史写成认识朋友

故事先让人物进入玩家的日常，再逐渐展现他们所属的历史。

历史事件因此与具体的牵挂相连。某个时代为何值得保存，不只由设定说明，也由珍惜那个时代的人来呈现。

### 6.2 日常愿望为重大选择提供重量

喜欢晒太阳、珍惜艺术、期待漂亮衣服、想与朋友再聊一会儿，这些愿望让人物拥有可感知的生活。

当人物付出代价时，玩家能够理解代价的内容。可用于创作的原则是：先让角色拥有值得继续的日子，再决定什么会迫使他作出艰难选择。

### 6.3 秘密改变对旧场景的理解

爱莉希雅身份与过去的揭晓，使她此前对芽衣的关注、回避与迟疑获得了新的意义。

揭密的价值可以通过一个问题检验：读者知道答案后，是否会重新理解已经看过的人物行为？

### 6.4 已知败局与未知选择同时存在

前文明的失败是背景，记忆体的当前行动仍在展开。悲剧的既定性与人物的自主性能够同时成立。

这给故事留下两种期待：了解过去为何如此，以及见证角色现在会怎样做。

### 6.5 核心人物可以通过影响他人形成故事

爱莉希雅的核心信念相对稳定。她对人的热爱与主动靠近，影响着周围的人，也影响芽衣理解世界的方式。

这种人物需要具体互动支撑。旁人的评价只能补充塑造；真正使信念可信的，是她如何面对不同的人、如何付出、如何处理自身的不安。

### 6.6 记忆与传承需要保留个体差异

英桀们对生活与责任的理解各有不同。共同参与一场行动，并不要求他们拥有完全相同的理由。

传承也可以保留差异。后来者理解前人的选择，仍然能够调整方向、反对某种方法，走出自己的道路。

### 6.7 情感表达依赖铺垫，也需要节奏控制

乐土通过大量对话建立关系。对于已经喜欢人物的读者，这些相处本身有价值；对于尚未建立感情的读者，信息分散与反复延后揭密可能成为负担。

借鉴时应同时检查：

- 每一段相处是否让人物关系发生变化。
- 每一次隐瞒是否有角色自身的理由。
- 每一阶段是否提供了可理解的新信息。
- 高潮中的牺牲是否具有不同的动机、行动与后果。
- 主角是否真正影响结果，而不仅负责听取解释。

## 7. 与《雨世界》的对照

下表是两部作品在本次讨论范围内的比较，不意味着它们具有完全相同的主题或创作目的。

| 关注方面 | 《雨世界》 | 往世乐土 |
| --- | --- | --- |
| 接近过去的方式 | 穿行遗迹，理解仍在运行的设施与留下的生命。 | 与记忆中的人物直接交流，逐渐进入他们的关系。 |
| 情感积累 | 环境、距离感、漫长变化与关键回应。 | 日常相处、群像关系、秘密与共同经历。 |
| 主角的位置 | 小生命进入远大于自己的旧世界。 | 后来者成为旧时代的见证者、参与者与回应者。 |
| 时间的表现 | 世界衰败、生态变化、遗产持续影响后来者。 | 历史回忆与当前事件交替，旧日选择在未来得到回应。 |
| 告别的体验 | 接近仍被执念、责任和时间影响的存在。 | 与已经熟悉的人共同完成有意识的告别。 |
| 延续的方式 | 救助、迁徙、陪伴或有限的改变继续发生。 | 记忆与愿望由后来者承接，并影响其未来选择。 |

**共同的研究问题**：主角如何进入一个早已开始的故事，并通过自己的行动，改变那些往事对现在的意义？

## 8. 留给《憨之轨迹》的借鉴方向

本节仅记录可讨论的叙事方法，不增加原作角色设定，也不直接改写《憨之轨迹》的剧情。

### 8.1 为角色安排可辨认的日常愿望

在重大冲突之前，让玩家知道角色喜欢什么、害怕什么、平时怎样与别人相处。

后续行动可以回应这些愿望。是否牺牲、是否离开、是否选择留下，都需要结合具体人物决定。

### 8.2 用人物关系承载世界观信息

介绍历史时，可以关注历史怎样改变一个人的生活与关系。

需要讨论的重点是：玩家通过谁接近这段历史，以及哪些情感变化会促使玩家继续了解。

### 8.3 让后来者带来具体的回应

如果故事中存在等待、遗愿或未完成的往事，主角的作用可以通过实际行动体现。

这种回应的规模可以很小。完成一次约定、帮助一个人重新作出决定，也能够改变往事在当下的意义。

### 8.4 让回忆中的人物保有选择空间

若未来采用记忆、残留意识或历史重现等表现方式，需要明确它们能做什么、不能做什么，以及当前行动会造成怎样的结果。

叙事应保持这些边界一致，使玩家理解“重现”“消失”“记住”和“改变”分别意味着什么。

### 8.5 控制群像规模与告别密度

十三英桀的效果依赖大量相处、对话与表现资源。毕业设计应根据能够完成的篇幅，决定实际需要多少角色。

应优先保证少数重要关系的发展完整，再考虑扩展人物。连续告别也需要不同的动机与后果，避免依靠数量推动情绪。

### 后续讨论需要确认的偏好

- 用户最喜欢的是爱莉希雅的核心故事，还是整个十三英桀群像？
- 更有吸引力的是日常相处、身份揭密、跨越时间的回应，还是最终告别？
- 是否希望自己的游戏包含记忆空间、旧时代人物或未完成的约定？
- 期望结局带来的主要感受，是释然、遗憾、希望、陪伴，还是继续生活的力量？

以上问题留待继续研究与讨论，不作为当前创作决定。

## 9. 资料使用与理解边界

### 9.1 资料类型

- **游戏文本存档**：正文多数链接来自《崩坏3》文本整理站，属于社区保存的游戏对话转录。它可用于定位原作对白，但该网站本身并非米哈游官方网站。
- **官方动画**：《因你而在的故事》用于对应最终演出。
- **社区资料页**：仅辅助确认篇章关系，不用社区推测替代游戏已经明确的情节。
- **本文分析**：人物概括、叙事方法、作品比较和借鉴方向，均属于本次讨论形成的解读。

### 9.2 容易混淆的内容

1. 往世乐土独立剧情与主线第29—31章需要连起来阅读，但两者的事件阶段应分别说明。
2. 英桀本人、记忆体和其他人对其保存的记忆，具有不同的叙事位置。
3. “第十三律者”不能直接当作爱莉希雅真实诞生顺序的说明。
4. 爱莉希雅的贡献为未来留下可能性，没有取消后世人物的自主选择。
5. 不能将“极恶”的行为直接等同于维尔薇全部的意图。
6. 帕朵的关键行动有明确任务与代价，不宜只概括成缺乏因果的煽情片段。
7. 爱莉希雅的重现依赖本篇具体设定与人物行动，不应推导成普遍、无代价的复活规则。
8. 乐土谢幕不等于抹除前文明曾经发生过的历史，也不等于所有英桀的现实本人在这一刻死亡。

### 9.3 本次整理保留的留白

本文没有穷尽十三英桀各自的追忆档案，也没有逐条展开前文明所有律者事件、延续计划及后续主线的设定解释。

若后续要重点借鉴某位人物的具体弧线，应针对其完整档案与相关章节继续阅读，避免用一行人物概括替代完整经历。

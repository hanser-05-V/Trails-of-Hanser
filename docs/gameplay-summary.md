# 《憨之轨迹》玩法阶段性总结

项目：憨之轨迹 / Trails of Hanser

记录日期：2026-09-30

范围：玩法交接资料与本次讨论中确认的规则；尚未创建工程或实现功能。

## 1. 阅读说明与状态区分

本文记录当前玩法基线，不是完整实现规格或最终数值策划案。

- **已确认**：可以作为后续讨论的共同前提，不需要逐条重新确认。
- **暂定**：用户同意先采用，但允许后续根据卡牌和关卡设计调整。
- **候选**：只提出了方向，尚未批准为当前规则。
- **待定**：仍需后续讨论，不应由实现者自行补成设计结论。

除明确标注“暂定”“候选”“待定”的内容外，下文规则均为已确认内容。

背景、人物与开场剧情继续参照 [game-setting.md](game-setting.md)。[README.md](../README.md) 与 [open-questions.md](open-questions.md) 保留了较早阶段的玩法描述，本次未修改；其中“战斗形式未定”“单人或队伍待定”等旧描述，涉及已在本文明确的玩法时，以本文为准。原有剧情设定不因本文而变更。

## 2. 游戏方向与表现

### 2.1 整体方向

- 使用 Unity、C#。原文档方向为 2.5D，具体美术形式、镜头与实现方式仍待细化。
- 单个毛怪主角进行故事，没有可操控队伍。
- 剧情驱动，以节点式关卡推进；关卡数量、具体剧情节点流程以后再设计。
- 每个独立关卡采用小型箱庭，包含战斗、走动、拾取、对话。
- 一个独立关卡内部可以包含多个小场景或多场战斗；它们不等同于新的独立关卡。
- 核心战斗体验是提前备招、组合释放，以及读取敌人意图后走位反制。

### 2.2 参考体验

以下记录用户希望参考的体验，不代表照搬这些游戏的完整机制，也不构成已核实的机制说明：

| 参考作品 | 希望参考的方向 |
| --- | --- |
| 《不思议的皇冠》 | 房间表现 |
| 《The Land Beneath Us》 | 小关卡规模 |
| 《斗技场的阿利娜》 | 六边形战场 |
| 《将军 对决》 | 提前备招、组合释放、读意图后走位反制 |
| 《崩坏3》 | 用户描述的节点式剧情推进方向 |
| 《游戏王》 | 按卡片张数自行搭配卡组的感觉 |

早期文档还提到《空之轨迹》《黎之轨迹》。后续涉及参考游戏的具体机制时，优先核对官方资料；必须区分原版《空之轨迹》和重制版。

### 2.3 毛怪形象

- 白色绒团、简单表情，没有明显外露的手脚，可以有皮肤和配饰。
- 身体撞击可以作为普通攻击的表现。
- 武器使用时出现，动作后收起；用小圆点表示握持，不画实际的人形手臂。

## 3. 探索与战斗切换

- 战斗外使用 WASD 四向探索；战斗内使用六边形网格，主要通过鼠标操作。
- 同一小场景可以承载探索和战斗。
- 战斗期间封闭区域，胜利后打开，恢复探索和交互。
- 探索进入战斗时，毛怪就近对齐当前位置附近的可用六边形格子；排除障碍物和被占用的格子。
- 每场战斗开始时，敌人先展示意图，由玩家先行动。
- 每场战斗都从空准备队列开始；战斗外不能提前备招。

距离相同的候选格如何选择、附近没有可用格时如何处理，属于待细化的站位边界。

## 4. 三类卡牌与战前配置

三类卡牌承担不同职责，不能把它们混为同一个随机手牌系统。

| 类别 | 获得与可用方式 | 是否进入准备队列 | 使用是否消耗回合 |
| --- | --- | --- | --- |
| 基础卡 | 每个玩家回合开始补齐缺失的普攻、基础移动 | 否 | 是 |
| 招式卡 | 关卡前选择携带，开战时所携带招式可选，使用后受冷却限制 | 是 | 加入一招消耗一回合，释放整组再消耗一回合 |
| 额外能力卡 | 永久解锁后可在关卡前装备，关卡内从配置的卡组随机抽取 | 否 | 使用本身不消耗回合 |

这里“招式初始都有”指本次携带的招式不依赖随机抽取，不代表所有尚未获得的招式都已解锁。同关后续战斗仍继承剩余冷却。

### 4.1 基础卡

- 基础卡包括身体普攻和基础移动。
- 它们独立于准备队列和额外能力卡，直接操作使用，不进入队列。
- 每次玩家回合开始，补齐缺失的普攻卡和基础移动卡；已有的不重复叠加。
- 普攻需要有效目标，不能空挥；没有目标时不执行、不消耗卡或回合。
- 点击移动卡后显示可达位置，再点击有效落点完成移动，确认执行后消耗卡和回合。
- 查看范围、取消选择不消耗卡或回合。
- 即使队列非空，也能普攻或移动，并保留已准备的招式。
- 另有独立等待按钮，等待消耗一回合。

### 4.2 招式卡

- 招式主要包括武器攻击、技能和魔法等需要加入队列的能力。
- 通过关键节点获得新招式。
- 进入独立关卡前，选择有限数量的招式携带；当前基线是整个关卡内配置固定。
- 所携带且不在冷却中的招式可以选择准备，不靠随机抽牌决定是否可用。
- 冷却结束后，招式回到可选的招式牌库区域，不会自动加入准备队列；再次准备仍需消耗一个回合。
- 招式总数、携带上限、队列容量待定。
- **暂定初始配置**：两个招式，一个攻击类、一个位置类；身体普攻独立存在。具体效果未设计。
- **候选机制**：未来地图可能加入泉水等建筑，允许关内临时更换技能配置。这尚未成为当前固定配置规则的正式例外；可更换范围、代价与冷却处理均待讨论。

### 4.3 额外能力卡：收藏与关内手牌

- 额外能力卡在游戏过程中解锁，解锁后永久拥有；失败不会失去已解锁的收藏。
- 每个独立关卡开始前，玩家从收藏中自行搭配并装备本次使用的卡组。
- 失败返回主界面后，可以调整配置，再重新进入关卡。
- 永久收藏与关内临时手牌是两层状态：卡组中的卡需要在关卡内随机抽到，才能作为手牌使用。
- 每个玩家回合开始，有概率从配置的卡组抽到额外能力卡，不保证每回合都有。
- 未使用的手牌可以保留。同一关卡内部继续战斗时保留关内状态；重新开始关卡时重置。
- 同名卡可以配置多张，也可以同时持有多个副本。
- **暂定配置限制**：普通卡同名最多携带 3 张，强力卡最多携带 1 张。具体哪些卡受何种限制，以及卡组总张数，等卡牌设计后再确定。

### 4.4 抽牌、弃牌与洗牌

- 抽到手里的卡从当前抽牌堆移出。
- 使用或弃掉的卡进入弃牌堆。
- 抽牌堆耗尽后，将弃牌堆重新打乱，作为抽牌堆继续抽取。
- 尚在手里的卡继续保留，不参与洗牌，不凭空生成额外副本。
- 只有额外能力卡计入手牌上限。
- 回合结束时若超过手牌上限，由玩家选择弃牌；达到上限但未超出时不弃牌。
- 配置数值时须保证卡组总张数大于手牌上限。两项具体数值仍待定。

### 4.5 使用阶段与免费效果

- 额外能力卡只能在玩家的准备阶段使用。
- 这里的准备阶段指消耗回合的行动执行前，可以自由操作的阶段，不是只能在点击“加入招式”时用卡。
- 开始释放整组连招后，已经进入执行阶段，不能插入使用额外能力卡。
- 使用额外能力卡本身不消耗回合，也不触发新一轮补牌、冷却推进或敌人行动。
- 具体特殊效果以未来卡片设计为准。
- “两倍移动”仅为已有示例；“获得额外行动、让玩家连续行动两次”仅为候选效果，均不代表具体卡牌已经定稿。
- 若以后设计额外行动，其补牌、冷却和行动时序规则届时再讨论，不自动套用普通回合。

## 5. 移动、占位与阻挡

- 当前基础移动只能到周围相邻一格的六边形格子。
- 移动卡显示相邻范围内可到达的落点，由玩家选择一个。
- 格子上有障碍物或被其他角色占用时，不能进入或停在上面。
- 以后可能通过 Buff、强化升级等改变移动能力；当前只保留扩展需求，按一格设计，不确定升级形式，也不进入代码实现。
- 更远移动的路径、途中阻挡、穿越占位等规则，留到相关能力设计时讨论，不能从基础一格移动自动推导。

## 6. 准备队列与连招执行

### 6.1 准备阶段

- 加入一招消耗一回合。
- 同一招在队列内最多一份，不能重复加入。
- 移动、普攻后保留已准备招式；普通受伤不会丢失已准备招式。
- 释放前可以免费拖动调整顺序。
- 可以免费移出已准备招式，但准备时消耗的回合不退还。
- 移出的招式没有释放，因此不进入冷却；再次加入仍消耗一个准备回合。
- 调整队列、查看范围、调整朝向等免费操作，不推进回合。

### 6.2 执行阶段

- 使用独立按钮释放队列，整组队列释放只消耗一回合。
- 开始释放后，队列顺序固定。
- 逐招选择方向，选择期间等待玩家输入；调整朝向不额外消耗回合。
- 整组执行完后，敌人才行动。
- 队列必须执行到底，不能取消、跳过或保留剩余招式。
- 原目标死亡后，后续动作仍执行；可以选择其他方向或目标，没有目标也照常空挥。
- 已执行的招式照常进入冷却。
- 普攻不入队，其“无有效目标不能执行”与队列招式的“允许空挥且必须执行”是不同规则。
- 已确认先执行完整组队列，再处理整组结束后的正常结算；执行过程中若出现玩家致命伤害等特殊中断，具体优先级尚需细化。

### 6.3 界面操作基线

- 普攻点击基础卡直接操作；移动点击基础卡后选择落点。
- 招式点击后加入准备队列。
- 释放队列与等待使用独立按钮。
- **保留备选**：“普攻入队并延续前一武器攻击”不属于当前玩法。

## 7. 回合与冷却

普通回合可按以下已确认关系理解：玩家回合开始补齐基础卡，并进行概率抽取额外能力卡的处理；玩家可以进行免费操作，再执行一个消耗回合的行动；该行动完成后进入敌方行动，完整回合结束时统一处理相应结算。

- 消耗一回合的行动包括：基础普攻、基础移动、加入一招、释放整组队列、等待。
- 额外能力卡、选方向、调整队列等免费操作不单独产生回合结算。
- 招式采用回合冷却，释放并完成执行后进入冷却。
- 每个完整回合结束时统一结算冷却。
- 本回合刚释放的招式，本回合结束时不递减，从下一回合结束时才开始递减。
- 整组连招只产生一次回合结算，不按招式数量额外推进冷却。
- 战斗外冷却暂停；同关下一场战斗继承剩余冷却。
- 各项回合末事件之间的精确顺序，以及未来特殊卡牌带来的例外，仍需按具体机制细化。

## 8. 敌人决策与意图

### 8.1 行动与进攻欲望

- 敌人按出现时机形成行动顺序。
- 各自有内部进攻欲望值，逐回合积累，进攻后下降。
- 进攻欲望结合距离、冷却、蓄力等条件参与决策；具体数值和公式待定。
- 玩家不看欲望条或具体欲望数值，只看下一回合的行动意图。
- 意图需要表达移动、备招、攻击、等待，以及相关位置或范围。
- 邪祟按具有普攻、法术等能力的常规敌人设计，尚未确认额外的情绪干扰战斗系统。

### 8.2 锁定方向、位移与误伤

- 常规方向攻击预告后锁定朝向，不因毛怪移动而重新瞄准。
- 毛怪走出范围后，敌人仍按预告方向执行，允许打空，不自行改成其他攻击。
- 敌人被击退时，攻击范围随其新位置平移，朝向保持不变，预告相应更新。
- 敌方伤害攻击可以误伤其他敌人，预览应显示可能受影响的目标。
- 具有特殊追踪机制的招式可以成为例外，具体规则以后设计；普通攻击不自动获得追踪能力。
- 指定地面法术、打断等特殊效果仍待具体设计。

### 8.3 预告动作无法执行

- **暂定**：已预告的移动落点在执行时被占用，则本次移动失败，原地结束行动。
- 不临时改换落点，也不临时替换成未预告的攻击。
- 这一条目前解决移动落点被占用的情况，不代表所有特殊动作失败后的处理都已确定。

### 8.4 意图显示方式

采用自动显示重点范围与鼠标查看相结合的方式：

- 所有敌人常驻显示行动图标。
- 距离玩家较近的敌人自动显示攻击范围；“较近”使用固定距离判断，具体几格以后确定。
- 即使距离较远，只要下一次行动的攻击范围覆盖玩家当前位置，也自动显示。
- 鼠标指向敌人时，显示其详细意图、相关范围及可能受影响的目标。
- 玩家移动或敌人被击退后，显示随局面更新；显示更新不等于改变敌人已锁定的攻击方向。

## 9. 增援、胜负与失败重开

### 9.1 增援出现

- 新敌人正式出现前一回合，提示其出现位置。
- 下一回合正式出现，之后按正常敌人规则行动并展示意图。
- 出生提示展示位置，不要求提前展示首次攻击范围。
- 当前不设计登场就攻击的怪物。
- 不采用此前建议的“先正式登场，再额外等待玩家一个完整回合”的通用规则。
- 正式入场处于下一回合的哪个结算节点，以及出生格临时被占用时如何处理，仍待细化。

### 9.2 胜利与失败

- 必须解决当前战斗的全部敌人，包括尚未登场的增援，才算胜利。
- 场上暂时没有敌人、但仍有待登场增援时，战斗继续。
- 毛怪与最后一个敌人在同一次效果结算中同时死亡，算失败。
- 正常胜负检查须结合整组队列执行到底的规则；更复杂的特殊中断结算不在本次定稿范围内。

### 9.3 关卡状态与重开

- 独立关卡是状态重置单位，进入新关卡按初始状态开始。
- 同一独立关卡内部的小场景和战斗之间，继承手牌、剩余冷却及此前消耗。
- 每场战斗仍从空准备队列开始，战斗外不能备招。
- 战败后播放战败表现，返回主界面。
- 玩家可以调整配置，再从当前独立关卡开头重新开始；包含此前的探索、剧情和战斗，关卡临时状态重置。
- 已永久解锁的额外能力卡收藏不丢失。
- 不再采用“仅重试失败的这场战斗，恢复本场开战时状态”的方案。

### 9.4 重开时的随机序列：待定衔接

此前在“重试当前战斗”的前提下，用户认可保持相同随机获得序列，包括各回合是否抽到卡和抽到什么卡。后来失败流程改为“返回主界面、可重新配置、整关重开”。

目前尚未明确旧序列规则如何适用于新流程，不能直接宣称已确定整关使用同一固定序列。后续需要处理：不改配置时是否复现整个关卡的序列，改配置后如何生成序列，以及卡组耗尽后的洗牌如何纳入重开规则。

## 10. 暂定与候选清单

### 10.1 已同意先采用的暂定项

- 初始两个招式：一个攻击类、一个位置类；另有独立身体普攻。
- 普通额外能力卡同名最多 3 张，强力卡最多 1 张；最终限制随卡牌设计调整。
- 敌人预告的移动落点被占用时，移动失败、原地结束行动，不临时替换动作。

### 10.2 尚未成为当前规则的候选项

- 通过 Buff 或强化升级改变基础移动能力；现阶段仍为一格。
- 泉水等地图建筑允许关内临时更换技能配置。
- 额外行动等能力卡效果，以及它们对补牌、冷却和行动时序的特殊处理。
- 特殊追踪、指定地面法术、打断等具体机制。
- 普攻入队并延续前一武器攻击，仅作保留备选。

## 11. 后续待讨论事项

不必在继续剧情与玩法讨论前一次性解决，按需要逐项推进。

### 11.1 规则边界

- 整关重开与战前重新配置情况下的随机抽取、洗牌复现规则。
- 增援正式出现的精确结算时点，以及出生位置被占用时的处理。
- 探索切入战斗时，等距离可用格和无可用格的站位处理。
- 更远移动如何经过路径、障碍和其他角色。

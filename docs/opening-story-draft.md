## 1. 故事的感情基础

主角是一只普通毛怪，是许多毛怪中的一员。它曾离开小镇，探索自己的生活；这次结束一段旅行，带着见闻回来，原本想与憨和朋友们分享。

它对憨的感情，核心是长久陪伴积累起来的深厚感谢。

憨陪它度过低谷，是它想分享喜悦的对象，也教会它许多道理。它从心底佩服、感激憨，并把她视为学习的目标。

作者对这份感情的原始表达：

> 更多是一份很深很深的感谢吧，憨对我来说，是陪伴我度过一个个低谷的朋友，是我分享喜悦的对象，是教会我很多道理的导师，是我不用费力就能抓住的依靠，也是我人生里不可多得的宝藏。她是我打心底佩服、感激的人，也是我学习的目标。

主角原本攒了一路想讲给憨听的话。得知憨的意识一直留在空间中、外面的情况已经发生变化后，它逐渐产生了新的愿望：去见她，让她知道还有人在牵挂她。

这份感情不预设为恋爱，也不预设憨与主角有特殊私交。

## 2. 世界与人物

### 2.1 憨的困境与卡带空间｜已确认的作者背景

憨是毛怪小镇的神主。

在完成一次演唱会活动后，她觉得自己作为 Hanser 走过的人生已经很圆满，许多愿望已经实现，一时找不到新的努力目标，也不知道以后该怎样生活。

她开始思考：自己一直在扮演 Hanser 这个角色，那么离开这个身份之后，真正的自己是谁？她也不知道该怎样面对毛怪们的感情，希望大家能够更加关注自己的生活。

这些疑问使她逐渐变得郁郁寡欢。她与银狼商量之后，由银狼用卡带创造了一个供她独处、思考的空间。憨的意识进入其中，此后一直没有返回。

外部留下的人偶起初依照预设的机械指令行动，后来逐渐将憨的愿望理解成了极端的目标。真正的憨仍在空间中思考，不知道外面发生的变化。

卡带空间的进入方式已有方向；意识如何返回、是否存在阻碍、终局如何与她取得联系，尚未决定。本稿不将“返回通道被锁死”写成事实。

### 2.2 人偶的判断与封闭计划｜已确认方向

人偶认为，毛怪们的感情和一个个期待，给真正的憨带来了很大压力。它固执地相信：去除这些期待与牵挂，就能让憨更好地做自己。

它命令银狼制作能够影响思想的工具，通过相应的思想空间，潜移默化地改变小镇居民，让他们逐渐失去与憨有关的诉求。

起初，“让憨休息，让毛怪更多关注自己的生活”能够得到神使的支持。随着执行推进，人偶的标准越来越极端：不仅要减少过度索取，连等待、怀念和珍惜过去也逐渐被视为应当消除的东西。

小镇中有人因此逐渐失去原有的情感，也有人彻底离开。故事层面可对应离开这个共同体；“注销账号”是创作时的比喻，具体呈现尚未设计。

但仍有毛怪不断从外部进入，带来新的情感、记忆与期待。人偶因此打算封闭小镇，将这里变成与世隔绝的地方。

本版目标是改变并封闭这里。旧版向外界传播侵蚀的计划已经撤下。

终局对手确定为人偶憨。旧稿“邪主”是否继续作为它的称谓，留待统一；不再将这一称谓解释成另一个附身人偶的外来首领。

### 2.3 神使为什么受到控制｜已确认方向

满穗、银狼、布洛尼亚暂列为首批客串角色。在本作同人世界中，她们属于神使。具体角色版本与后续遭遇尚未展开。

神使通常服从神主，但保有自己的感情与判断，能够对命令产生异议或拒绝执行。

她们起初支持让憨休息。后来，人偶的做法逐渐伤害居民，神使开始质疑并尝试阻止。人偶则认定：神使也被这些感情束缚，她们的反对会让憨重新承受压力。

于是，人偶将思想干预也用于神使，逐步改变她们的判断，使她们相信，消除毛怪的依恋与期待是在保护憨。

本版以“思想干预”描述这一过程。它具有渐进性，神使的怀疑、动摇、掩饰和反抗仍有发生的空间。

卡带思考空间、用于思想干预的工具与空间、能力投影道具魔导盘，各自承担不同用途。它们是否共用某种技术，尚未讨论，不直接写成同一件装置。

### 2.4 满穗的转变与逃亡

已确认的人物方向：

满穗起初也认可让憨休息，愿意配合。她后来亲眼发现，人偶连没有给憨施加压力的感情也要求消除，才开始怀疑。

她能够理解这种“舍不得”，与银狼送给她的魔导盘有关。她一直珍惜这份朋友的礼物，亲身知道关心与回忆能够给人带来安慰。当人偶要求居民连这些也放下时，她会想到自己同样舍不得丢掉的东西。

作为这一转变的具体事件，目前保留以下衔接提案：

> 满穗接触到一只已经接受憨今后可能不再出现、也准备回到自己生活的毛怪。它只想保留一件与过去有关的纪念物，但这份留恋仍被列入需要消除的范围。

这只毛怪的身份、纪念物是什么、事件发生地点及对白尚未决定。该事件可作为作者背景，不要求额外加入开场可玩场景。

满穗开始隐藏疑问，以沉默和装哑巴掩饰自己的态度，继续潜伏，随后得知封闭计划，带走属于自己的信物逃出。

她已经受到思想干预，仍保留着理智；干预与逃亡也使她十分虚弱。她的经历以逐渐察觉、主动掩饰和采取行动为主，不再仅靠“能力弱，所以被忽略”解释。

她受到干预的具体过程、怎样争取到潜伏和逃离的机会，仍需补充。沉默是掩饰行为，不自动构成抵抗思想干预的能力。

毛怪认识满穗，也知道她能够说话。开场不安排“原来你会说话”的惊讶对白。

### 2.5 满穗知道什么｜开场的信息边界

满穗能够向毛怪说明的内容，以她亲眼观察或潜伏得知的事实为限：

| 信息 | 开场可用范围 |
| --- | --- |
| 演唱会结束后，憨过了一段时间开始郁郁寡欢 | 满穗观察到的变化 |
| 憨与银狼商量，由银狼用卡带创造空间 | 满穗掌握的经过 |
| 憨的意识进入空间，此后没有返回 | 满穗知道的事实 |
| 外部的“神主”开始改变，接连下达指令，神使也逐渐变化 | 满穗的观察与亲历 |
| 居民的感情受到干预，神使的异议也被纠正 | 满穗逐渐发现的问题 |
| 人偶正在谋划封闭小镇，追索神使信物 | 满穗潜伏得知的计划；信物的技术用途仍待定 |
| 憨对自我、人生目标和毛怪感情的完整内心思考 | 作者背景，不直接当作满穗已经听过的自述 |
| 人偶全部推理、真正的憨不知道外界变化 | 作者背景；角色在开场能确认到何种程度仍需安排依据 |

满穗可以判断外部指令出了问题，也知道真正的憨一直没有返回。她不应在一次战后说明中完整讲出所有人的内心。

### 2.6 信物、封闭计划与邪祟｜保留方向与待定机制

保留的剧情方向：

- 神使拥有各自的烙印信物。
- 满穗潜伏得知封闭计划后，带走属于自己的信物，试图阻止计划。
- 追兵需要追回她带走的信物，构成开场追逐的原因。
- 信物能够通过魔导盘提供对应神使的能力投影。

仍属衔接提案的封闭机制：

> 烙印信物维系神使与外界的联系。人偶必须将所有信物接入封闭装置，才能彻底隔绝这个世界；缺少满穗这一份，封闭便无法完成。

“每份信物对应独立联系”“必须集齐全部”“信物如何接入装置”均未最终确认。后续需据此解释人偶为何必须追回满穗的信物；暂不写入具体数量、复制限制或毁坏规则。

开场与后续普通追兵暂沿用“邪祟”称呼，受人偶驱使。它们为何出现、怎样形成，仍待决定。此前提出的“思想干预指令借神主力量具现为执行者”保留为候选，不作为已经确认的起源。

### 2.7 主角的条件

主角长期在外，接触小镇思想干预的时间较短，仍保留着相对完整的记忆和丰富的情感。它没有永久免疫能力。

它能够辨认满穗，了解她的故事，并对她的经历怀有足以支持能力投影的感情。这些感情可以来自理解、心疼、敬佩与共鸣，不需要预设两人有特殊私交。

熟悉程度作为能力成立的基础，不在首战前安排知识测验或长篇回忆。

## 3. 魔导盘、银狼的礼物与能力投影

### 3.1 礼物的来由｜已确认

银狼认识满穗之后，总是拉着她一起玩游戏。

她平时贪玩，说话做事也有些不着调。但在逐渐知道满穗的经历后，她认真地想给这个朋友做点什么，让满穗也能亲自体验那些奇妙的能力。

于是，银狼制作了魔导盘。按照她的介绍，放入对应的烙印信物，就可以投影出信物所属者的能力，让使用者暂时拥有相应的力量。

送出魔导盘时，银狼还附上了自己的烙印信物。她原本希望满穗能够体验一下自己的力量。

满穗当时还没有深入了解银狼的故事，也没有真正使用过魔导盘。听着那些神奇的介绍，她以为银狼又在想办法哄自己开心。不过，她还是收下了，也一直把它留在身边——这是朋友送给她的礼物。

直到开场毛怪通过满穗的信物使出力量，她才亲眼发现：银狼当时说的事情，真的能够实现。

“没有真正使用过”暂按用户原意保留，不补写一次失败测试或一次成功体验。银狼信物在开场的去向也不在这里推定。

### 3.2 试玩品的 Bug｜已确认的道具规则

魔导盘还是一个试玩品。它有一个限制使用的 Bug：

- 使用者必须了解信物所属者的故事。
- 使用者必须对其怀有一定感情。
- 能够发挥的力量程度，取决于相关情感与回忆的深度。

信物提供能力投影的来源，使用者的了解、情感与回忆影响投影能否成立，以及能够发挥多少力量。

上述规则是作者已经确定的机制。银狼事前是否完全知道这个 Bug、满穗何时知道全部使用条件，尚需在对白衔接时确定，不默认角色掌握所有规则。

目前没有确认使用能力会消耗情感或回忆。“持续使用会淡漠、迷失或消失”仍属待讨论提案。

### 3.3 开场使用与待定边界

- 开场毛怪获得的是满穗信物提供的拟态力量。
- 使用力量后，主角外观出现对应变化；具体变化幅度和造型稍后设计。
- 首战前采用简洁的“拾取／佩戴 → 外观变化 → 战斗”。
- 本轮不增加复杂启动仪式或一长段教学对白。
- 魔导盘暂为统一工作名称；“魔导具”“戒指”的称呼与造型关系待美术设计时确认，不增加第二件独立装备。

赠送时附带银狼信物已经确认。开场时银狼信物是否仍在满穗身边、满穗自己的信物何时放入魔导盘、为何初次显现的是满穗的力量，仍需连贯说明。

这些问题会同时影响后续获得银狼力量的过程，以及信物参与封闭计划的规则，暂不以复制品、自动失效或归还等新设定代填。

## 4. 开场正文

### 场景一：返乡与神使广播

毛怪结束旅行，回到小镇外围。它带着想与憨和朋友们分享的见闻，尚未意识到小镇发生了什么。

广播中传来神使的发言。已经确认的核心信息是：

> “神主已经变了。”

发言神使的身份、她此时受到干预的程度、这句话是警告还是某种宣告，以及完整广播内容，尚未决定。

旧稿中由毛怪俱乐部发出的撤离通知及转述憨“最后清醒时”意愿的对白已经撤下，不作为新版广播内容。

毛怪仍在疑惑，觉得憨平时那么厉害、阳光，怀疑这又是一次整活。

此处保留主角尚未相信情况严重的反应，不扩写新对白。

### 场景二：追逐声与被打落的魔导盘

毛怪正在疑惑时，听见一阵追逐声。

满穗正被邪祟追赶。她从塔中逃出，又受到思想干预的影响，已经十分虚弱。追兵的目标是她带走的信物。

追击中，满穗携带的魔导盘被邪祟打落，落到毛怪门前、能够立即捡起的位置。门前与外围地图的空间关系待地图设计时落实。

满穗看见毛怪，喊它带着东西赶紧离开，自己转身拖住追兵。

按用户口述整理的短句草稿：

> “带上这个，赶紧离开这里！我来拖住他们！”

毛怪捡起魔导具，满穗信物的拟态力量生效，它的外观随之发生变化。

紧接着进入战斗。

本段保留简洁呈现：

**拾取／佩戴 → 外观变化 → 战斗。**

追兵把持有信物的毛怪视为目标，构成首战的直接衔接。

满穗信物装入魔导盘的前置过程仍见第 3.3 节待定项，不将补充过程变成长篇战前教学。

### 场景三：首战

毛怪使用满穗信物提供的力量，与战士型邪祟进行 1V1 战斗。

满穗无法作为第二名战斗角色参战。

具体初始技能、外观变化、数值和教学提示在后续设计中确定。

本稿不展开战斗动作和招式过程。战斗结束后进入毛怪与满穗的对话。

### 场景四：满穗解释世界的变化

脱险后，满穗向毛怪说明自己掌握的情况：

1. 演唱会结束一段时间后，憨开始郁郁寡欢。
2. 她与银狼商量，由银狼用卡带创造了一个空间；她的意识进入之后，一直没有返回。
3. 外部的神主随后发生变化，接连下达指令，小镇居民与神使也逐渐变化。
4. 满穗起初愿意配合，后来发现连无害的珍惜也被要求消除。她隐藏疑问，潜伏得知封闭计划。
5. 她带走自己的信物，试图阻止计划，因此遭到追捕。
6. 她已经受到干预，加上逃亡的消耗，如今十分虚弱，无法继续帮助毛怪直接战斗。

这些内容是本场对话需要交代的信息，不要求逐条讲解。具体分句和停顿留待对白阶段处理。

开场可让毛怪理解“真正的憨仍未回来，外部的行动已经出现问题”。人偶完整动机、憨的内心困境与信物技术细则，不全部塞入满穗的说明。

### 场景五：魔导盘的来由与“等后面……”

满穗接着解释魔导盘的来由。

她说起银狼过去总是拉她玩游戏，也说起这份让她体验奇妙力量的礼物。赠送时附带的是银狼自己的烙印信物；她当时以为朋友只是在哄自己开心，仍一直珍惜地收着。

保留用户提供的表达顺序：

**银狼的礼物 → 拟态条件 → 没想到真的有效 → 道歉 → “等后面……”的停顿。**

以下为口述内容的轻量断句整理，保留原有句子。新增前史暂以叙述和信息意图记录，不扩写成一整段新对白：

> “这个魔导具还只是个试玩品，是银狼为了哄我开心，特意做的。”
>
> “说是放上对应的信物，就可以获得拟态力量。但是需要使用者对放入信物的信息十分了解，而且感情丰富，才可以使用。”
>
> “没想到，居然真的可以使用。”
>
> “等后面再和银狼去道歉吧。等后面……”

关于条件的这句原话先保留；正式对白需与第 3.2 节的精确规则及满穗何时知情对应。

道歉的情感缘由采用本轮认可的衔接：满穗发现银狼当时认真做了这件东西，自己却一直以为对方只是说着哄她开心。

满穗说到“等后面……”时停下来。她想起银狼如今的处境，意识到自己已经无法像过去那样，随时去找这个朋友。

满穗陷入沉默。

这一停顿保留给玩家理解：刚才还在说熟悉的人和日常小事，她却无法确定何时才能再见到银狼。

### 场景六：托付信物与寄宿

沉默之后，满穗让毛怪带着魔导盘和信物离开这里。

从塔中逃出，加上思想干预留下的影响，她已经没有力量继续应对追兵，也无法保证自己始终保持清醒。

她最初的托付是保住自己带走的信物，阻止人偶完成封闭计划。信物如何阻止封闭，仍采用第 2.6 节中标明待确认的衔接方案。

后续陪伴方向已明确：

**满穗失去实体，以神魂寄宿的形式陪伴毛怪，在整个旅程中与它对话、提供指引。**

本稿保留以下衔接提案：

- 满穗将自己的意识寄存在属于自己的信物中。
- 毛怪携带信物与魔导盘，使她能够继续随行，并通过魔导盘与毛怪交流。
- 寄宿后，满穗无法独自移动，因此需要毛怪带着她走。
- 拟态力量仍由毛怪使用，满穗保有独立的意识、性格与记忆。
- 对话陪伴与战斗技能装配分别处理，后续更换技能不应让满穗失去陪伴功能。

从虚弱到失去实体的具体因果、寄宿动作、是否表现身体逐渐透明，以及将来能否恢复实体，尚未定稿。

这里不预设死亡或不可逆牺牲，也不新增告别对白。

### 场景七：小镇调查与恐惧

毛怪进入小镇，亲眼确认满穗说的情况。

居民变得木讷、失去生机。有人已经难以回忆憨的具体事情；有人仍然习惯性地祈祷、等待她的声音，却缺少曾经的情绪。

沿用现有 Demo 中两个必需调查点的功能：

- 一处表现记忆模糊。
- 一处表现习惯与依恋的残留。

具体居民身份、场景摆设和对白暂不编写。

看见这些变化，毛怪开始害怕。它刚刚借到力量，却也亲眼见过满穗的虚弱，不知道自己能够走多远。

满穗最初只希望它保住信物、离开这里。毛怪有退避的理由，试图用“不在乎”减轻自己的恐惧。它受到思想干预的具体表现尚未设计，不把这一念头直接等同于已经被控制。

本稿保留恐惧、退缩与当下自省的过程。

憨努努已从开场移除，不再承担触发作用；这部分也不加入具体往事的回忆过场。独白具体措辞待讨论。

### 场景八：前往憨塔的契机

战后对话已经让毛怪知道：

**憨的意识进入空间后一直没有返回，外部的行动正在伤害小镇。**

小镇调查使毛怪进一步明白，保住信物能够阻碍人偶的计划，却不能解决居民已经受到干预、憨一直未归的问题。

毛怪想起自己这次为什么回来：它有许多话想与憨分享，也始终感谢憨给予自己的陪伴。

现在，它希望能够找到真正的憨，让她知道外面发生了什么，也知道还有人在牵挂她。主角此时的愿望是取得联系，尚不知道怎样才能做到。

满穗从塔中逃出，可以为接近憨塔提供指引。她掌握的具体路线、卡带所在位置，以及怎样进入意识空间，仍需以后设计，不写成她已经知道完整营救办法。

毛怪仍然害怕，也不知道能否成功，但逐渐作出自己的选择：

**在满穗的指引下接近憨塔，设法与憨取得联系。**

满穗最初托付的是保住信物；前往憨塔、尝试帮助憨，是毛怪出于自身感情作出的决定。

满穗了解它的想法后，以同行者的身份帮助它。

本稿停在两人明确这一目标、准备向憨塔出发的节点。此处不新增出发宣言或沿途对白。

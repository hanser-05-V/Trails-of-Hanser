# 已确认设定与开场剧情

项目：憨之轨迹 / Trails of Hanser

记录日期：2026-09-29

范围：当前讨论已确认的设定。未定的原因、机制和关卡见[待讨论事项](open-questions.md)。

## 1. 世界与称呼

毛怪小镇因为憨的存在而存在。憨是这个世界的神主，居民是毛怪。

| 名称 | 当前含义 |
| --- | --- |
| 憨 / Hanser / 神主 | 同人世界中的核心人物，后来受到邪祟控制 |
| 憨老板 | 主角在日常表达中对憨的称呼 |
| 毛怪小镇 | 主角的故乡，正在受到侵蚀 |
| 憨塔 | 主角需要前往的目的地，与被控制的憨有关 |
| 毛怪俱乐部 | 憨身边的团队，发出最后的疏散广播 |
| 憨努努 | 主角随身携带的玩偶，开场中促使它醒悟 |

憨塔的建筑细节、居民口中的城堡与憨塔的具体空间关系，仍待后续设计。

## 2. 憨的变化

### 2.1 逐渐淡出

憨希望毛怪能够拥有自己的生活，找到其他生活支点。因此，她逐渐减少活动与出现，只是偶尔发出声音、回应毛怪。这个阶段彼此的联系仍然存在。

### 2.2 触发事件

某件事情使憨心情低落。事件的具体内容尚未确定。

“希望毛怪独立生活”并不直接等于“认为自己害了大家、所以决定彻底消失”。后者没有被采用为人物动机。

### 2.3 邪祟介入

邪祟趁憨情绪低落时靠近，逐渐隔绝喜欢她、鼓励她的声音，并放大负面感受。憨越来越封闭，最终受到控制，不再回应。

游戏开始时，憨已被控制，小镇正在逐渐衰败。前史可以在后续旅程中逐渐揭示，具体叙事方式待定。

## 3. 邪祟与侵蚀

### 3.1 成长方式

邪祟以负面情绪为养料。它通过隔绝善意、放大负面感受壮大自己，进而加深控制。

控制憨后，邪祟主动利用憨的力量侵蚀世界。

此前讨论中的“假憨色”指憨受到控制后呈现的形态。最终对手并不是另造的独立替身。“假憨色”目前是讨论用称呼，是否在游戏中使用尚未决定。

### 3.2 小镇的变化

- 小镇逐渐失去生机。
- 怪物开始滋生。
- 大雨、雷电等异常天气出现。
- 部分居民变得无精打采、木讷，情感逐渐消退。
- 居民对憨的具体记忆也逐渐模糊。

### 3.3 遗忘的规则

具体记忆逐渐消失，但感情、习惯和依恋仍有残留。

有的毛怪已想不起过去，却仍定时祈祷、等待憨的声音。它们继续重复熟悉的动作，眼里却失去了原来的光彩。

居民受到侵蚀的程度可以不同。目前尚未设置数值化的侵蚀系统。

### 3.4 被蛊惑的毛怪守卫

毛怪对憨有不同的喜爱方式，包括希望更靠近憨的粉丝、男友粉、女友粉等。

部分毛怪会受到邪祟蛊惑，守住城堡、阻挡玩家。邪祟可以利用它们遗忘后仍残留的感情与执念。

具体守卫的身份、愿望、经历，以及是否能够被唤醒，仍待讨论。

## 4. 主角

### 4.1 身份与返乡

主角是一只曾经离开小镇、探索自己生活的毛怪。开场时，它结束一段旅行，带着见闻返乡，原本想与憨和朋友们分享。

长期在外使它受到侵蚀的时间较短，保留着相对完整的记忆。它没有对邪祟的免疫能力。

### 4.2 开场就已受到影响

主角进入小镇外围、听到广播时，邪祟干扰已经开始。

后面的恐惧、退缩，以及“其实我没有那么喜欢憨”的自我说服，都与邪祟的影响有关。邪祟会放大主角的动摇。

### 4.3 感情变化

主角起初没有完全认识到这份喜欢对自己有多重要。

在寻找憨的过程中，它逐渐意识到憨对自己的影响，并发现自己原来如此喜欢憨。开场先以“她帮助过我，我想去帮她”作出行动选择，感情的认识在后续旅途中继续发展。

具体感情表达尚未确定为恋爱线。

## 5. 开场事件顺序

以下顺序作为当前开场基线。两次战斗之间包含小镇调查、主角退缩与憨努努触发醒悟的过程。

### 5.1 小镇外围：最后的广播

主角刚返回、进入小镇外围，听到毛怪俱乐部面向所有居民发出的紧急广播。这不是专门发给主角的消息。

广播说明憨已受到邪祟控制，团队无法控制局面，要求居民离开小镇，不要靠近憨塔或尝试对抗邪祟，并转达憨在短暂清醒时留下的疏散意愿。

已认可的广播草稿：

> 各位毛怪小镇的居民，这里是毛怪俱乐部。现发布紧急通知。
>
> 神主已被邪祟控制。我们尝试过阻止，但……已经无法控制局面。
>
> 请所有仍能听见广播的居民，立即离开小镇。不要靠近憨塔，也不要尝试与那股力量对抗。
>
> 神主最后清醒时，希望我们把这句话带给大家——
>
> 别再等我的声音了。去过你们自己的生活，好好活下去。
>
> 这是毛怪俱乐部最后一次广播。请尽快撤离。重复，请尽快——

通讯中断。

### 5.2 主角起初以为是在整活

主角尚未相信情况如此严重，觉得憨平时厉害、阳光，怀疑广播又是一次整活。

对话方向，措辞仍可润色：

> 通讯中断了？说得好真实……憨老板这么厉害、阳光的人，怎么会被控制？可能又是憨整活吧。

### 5.3 第一次战斗：战士型邪祟

主角突然遭到邪祟化身的小怪袭击。敌人是战士类型。

主角获胜后仍觉得不可思议，继续赶往小镇内部。具体战斗操作与敌人技能待定。

### 5.4 看到小镇现状

主角发现居民木讷、无精打采，情感消退。一些毛怪仍定时祈祷，但眼中已经没有原来的光。

它重新想起广播，意识到通知是真的。

### 5.5 恐惧与退缩

面对敌人与小镇的异状，主角怀疑自己能否战胜这样的力量，产生逃跑的念头。邪祟影响使它试图否认自己的在意。

已认可的独白草稿：

> 这样的敌人……我真的对付得了吗？
>
> 其实我也没那么喜欢憨老板。她只是我生命里的一个过客，听她的话，离开就好了……

### 5.6 憨努努：当下的醒悟

主角看见随身的憨努努，停住脚步，意识到自己正在用“不在乎”作为离开的理由。

此处不设置具体往事或回忆过场，直接表现当下的醒悟。尚未设定玩偶拥有独立的驱邪能力。

已认可的独白草稿：

> ……我在说什么啊。
>
> 她明明帮过我那么多。
>
> 如今她遇到困难，我却在这里找理由，装作自己根本不在乎……
>
> 能不能赢，我不知道。但我想去帮她。

主角暂时挣脱干扰，决定向憨塔进发。这里没有确定它此后永久不受侵蚀。

### 5.7 第二次战斗：法师型邪祟

主角作出决定后，新的邪祟出现，战斗再次开始。这次敌人是法师类型。

法师的具体台词、外形、登场动作和技能均未定稿。

## 6. 后续主线方向

开场之后，主角继续闯关，在寻找憨的过程中逐渐理解自己的感情。途中会遇到被蛊惑的毛怪守卫，最终抵达憨塔，与邪祟控制下的憨战斗。

结局方向是打破控制，让毛怪的祝福抵达憨身边，使小镇恢复。最终战阶段、祝福送达方式、憨的具体行动与结局演出尚未确定。

## 7. 设定维护原则

- 当前文档保存已经认可的内容；新的提议在确认后再并入。
- 广播和主角独白保存为已认可草稿，后续可以润色。
- 法师阻路台词、信件主角、特定老朋友开场、憨努努触发具体回忆等早期提议，没有纳入当前开场。
- 本文中的心理变化和邪祟事件均为同人虚构设定，不是现实人物经历的事实记录。

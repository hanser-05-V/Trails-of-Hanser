# 憨之轨迹 · Trails of Hanser

以 Hanser 与毛怪为主题的非官方同人毕业设计项目。正式游戏计划使用 Unity、C#，采用 2.5D 表现，围绕剧情探索与战斗展开。

## 当前进度

已完成独立的 **1V1 HTML 战斗参考版及 2.5D 镜头修订**，入口位于 [prototypes/hanser-duel](prototypes/hanser-duel/README.md)。

- 战前自由搭配四个普通技能与一个大招，按速度形成可见行动顺序。
- 攻击／技能／物品／大招菜单；技能可选卡点提供奖励，敌方攻击逐击闪避或精准格挡。
- 技力和大招能量独立；大招在完整行动后插入，保留原定正常行动。
- 透视场景、二维角色、视差与遮挡；角色旁菜单、目标预览、侧移、特写和动作跟拍。
- 鼠标和键盘均可独立完成战斗。**39 项自动测试通过**，已分别实际操作到胜利，并验证战败、重试、换装与大招；详情见 [验证记录](prototypes/hanser-duel/VERIFICATION.md)。

**用户于 2026-10-15 明确认可当前 HTML 玩法方向。** 后续先把开场剧情、探索、教学和美术基线确定，再制作可从头玩到尾的 HTML 整体最小 Demo，验证整段体验后进入 Unity。窗口、镜头与数值继续通过人工试玩调节。

整体路线：**D2 开场内容与美术基线 → D3 HTML 整体 Demo → D4 Unity 技术与美术样片 → D5 Unity 开场可玩切片 → D6 内容扩展与打磨 → D7 毕业展示交付**。D5 是最小可展示游戏；后续内容量结合可用时间和毕业要求确认。各阶段交付与验收见 [开发任务规划](docs/development-plan.md)。

**D2 进行中：D2-01 体验目标与范围已完成，D2-02 剧情节拍与教学进行中。** 用户于 2026-10-16 认可的 [《憨之轨迹》· 序章·归来](<docs/《憨之轨迹》· 序章·归来.md>) 初稿已完成；同日按用户补充设定与批准范围，更新为完整修订版话本，保留提要、正文、本章总结和后续剧情待续位置。新增设定已确认，修订后的完整正文待用户审阅。下一步先审阅新版，再继续确认法师型第二战接入与分段教学。

本次补充了神使统筹区域并维系外部通道、人偶剥夺情感、满穗察觉未受污染的毛怪归来后出逃、战后净化与缓慢恢复，以及寄宿信物保护主角。魔导盘仍要求了解信物所属者并怀有感情；主角未受污染，当前是唯一能够使用它的毛怪。首战结尾按批准调整为净化后满穗昏迷，路口退缩改为想先回家躲避；第二战具体接法仍待确认。

D2-01 已确定两处小区域、两场 1V1、两个必需调查点及一个可删的环境调查点，目标首轮体验约 10～15 分钟，从返乡到开始前往憨塔。范围、时长假设与验收见[开场 Demo 设计](docs/opening-demo-design.md)；旧版剧情描述与确认稿冲突时，以《序章·归来》为准。小说目前只展开首战，第二战仍属于 Demo 范围；其接入及两区域与家门、屋内对白的对应待设计。整体 Demo 和 Unity 工程尚未实施，时长尚未实测。可复制的接续提示见[开发交接](docs/development-handoff.md#9-给新会话的接续提示)。

旧版 [六边形卡牌原型](prototypes/hanser-html/README.md) 保留对照，其提前备招、抽弃牌与组合释放不再是当前战斗方向。旧 P1-01 不再作为默认下一项。

## 打开原型

用桌面浏览器打开 [新版 index.html](prototypes/hanser-duel/index.html)，在装配界面点击“进入试炼”。代码、样式与占位图形全部内嵌，无需 npm 依赖或构建。

实际浏览器验证通过本机 HTTP 服务完成；直接双击的 file:// 路径尚未实测。可复制的服务和测试命令见 [开发交接](docs/development-handoff.md)。本机预览进程不随 Git 同步；GitHub 的 HTML 链接用于查看源码，仓库尚未部署在线试玩站点。

## 开发方向

| 项目 | 当前方向 |
| --- | --- |
| 正式引擎与语言 | Unity、C#；版本与工程创建方案在移植前确认 |
| 当前验证载体 | 独立单文件 HTML / JavaScript 1V1 战斗参考版 |
| 画面表现 | 2.5D；HTML 透视与镜头已做参考，Unity 资产管线尚未验证 |
| 主角 | 单个白色圆团毛怪，无可操控队伍 |
| 核心战斗 | 战前能力搭配、速度行动顺序、直接选招、可选卡点、逐击应对与大招插入 |
| 内容方向 | 节点式剧情推进，关卡内探索与战斗衔接 |
| 美术计划 | 借助 AI 生成，由项目作者进一步设计与整合；当前为代码绘制占位图形 |

主角从失去生机的毛怪小镇出发，在寄宿于信物中的满穗陪伴与保护下前往憨塔，尝试与意识留在卡带空间中的憨取得联系。后续故事方向为战胜受控者后由满穗净化、战胜其他神使并获得信物，最终与人偶憨决战；具体敌人、期间对白及内容规模尚未展开。序章新增设定已确认，修订全文待审阅，实施前待定项见开发交接。

## 内容说明

本文档描述的是原创同人世界。神主、邪祟、情绪控制等内容属于虚构剧情，不是对现实 Hanser 心理状态或私人经历的事实陈述。本项目不代表 Hanser 或其团队的官方作品。

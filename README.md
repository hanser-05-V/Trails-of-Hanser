# 憨之轨迹 · Trails of Hanser

以 Hanser 与毛怪为主题的非官方同人毕业设计项目。正式游戏计划使用 Unity、C#，采用 2.5D 表现，围绕剧情探索与战斗展开。

## 当前进度

已完成首个 **HTML 可玩战斗原型（游戏画面版 03）**，保存于 [prototypes/hanser-html](prototypes/hanser-html/README.md)。包含六边形战场、拖动卡牌、提前备招、整组释放、敌人意图、冷却、抽弃牌、增援与胜负闭环。现有 40 项规则测试通过，实际验证范围见 [验证记录](prototypes/hanser-html/VERIFICATION.md)。

目前尚未创建 Unity 工程。下一步完善 HTML 的行动反馈与操作体验，试玩验证后再移植最小战斗场景。

- **换电脑继续开发：先读 [开发交接](docs/development-handoff.md)。**
- **任务顺序与验收标准：见 [开发任务规划](docs/development-plan.md)。**
- 下一项任务：**P1-01 行动过程与结果反馈**。规划不等于后续代码写入授权，实施前仍须确认文件范围。

## 打开原型

用桌面浏览器打开 [index.html](prototypes/hanser-html/index.html)，在配置浮层点击“进入测试战场”。HTML 自带代码和占位图形，无需 npm 依赖或构建步骤。

实际浏览器验证使用本机 HTTP 服务；直接双击文件方式尚未由自动化工具实测。家里电脑的服务和测试命令见 [开发交接](docs/development-handoff.md)。GitHub 的 HTML 文件链接用于查看源码，仓库尚未部署在线试玩站点。

## 开发方向

| 项目 | 当前方向 |
| --- | --- |
| 正式引擎与语言 | Unity、C#；版本与工程创建方案在移植前确认 |
| 当前验证载体 | 单文件 HTML / JavaScript 战斗原型 |
| 画面表现 | 2.5D；正式镜头与美术实现待细化 |
| 主角 | 单个白色圆团毛怪，无可操控队伍 |
| 核心战斗 | 六边形站位、读取敌人意图、提前备招、组合释放 |
| 内容方向 | 节点式剧情推进，关卡内探索与战斗衔接 |
| 美术计划 | 借助 AI 生成，由项目作者进一步设计与整合 |

主角从失去生机的毛怪小镇出发，一步步前往憨塔，面对被控制的憨，让毛怪的祝福抵达并推动小镇恢复。详细设定保留在剧情文档中。

## 内容说明

本文档描述的是原创同人世界。神主、邪祟、情绪控制等内容属于虚构剧情，不是对现实 Hanser 心理状态或私人经历的事实陈述。本项目不代表 Hanser 或其团队的官方作品。

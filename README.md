# 憨之轨迹 · Trails of Hanser

以 Hanser 与毛怪为主题的非官方同人毕业设计项目，计划使用 Unity 与 C# 开发，采用 2.5D 表现，围绕剧情探索与战斗展开。

## 当前阶段

正在逐步确定游戏设定。本仓库首先保存已确认的背景、人物、开场剧情与待讨论事项，尚未创建 Unity 工程或实现游戏功能。

- 主角：一只结束旅行、返回故乡的毛怪。
- 起点：毛怪小镇逐渐失去生机，居民遗忘憨，邪祟控制了神主。
- 旅程：主角克服退缩，一步步前往憨塔，并逐渐认清自己对憨的感情。
- 终点方向：与被控制的憨战斗，打破控制，让毛怪的祝福抵达，推动小镇恢复。

## 内容说明

本文档描述的是原创同人世界。神主、邪祟、情绪控制等内容属于虚构剧情，不是对现实 Hanser 心理状态或私人经历的事实陈述。本项目不代表 Hanser 或其团队的官方作品。
